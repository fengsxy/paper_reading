## 📊 核心投资理念总结

### 1. 品牌护城河
- 可口可乐（1988）
- 吉列（1989）
- 苹果（2016）

**关键**：品牌是最强的护城河，难以复制，提供定价权

### 2. 长期持有
- 可口可乐：持有 37+ 年
- 最喜欢的持有期：永远

**关键**：时间是优秀公司的朋友

### 3. 在别人恐惧时贪婪
- 1987 年黑色星期一：保持冷静
- 1990 年储贷危机：买入富国银行
- 2008 年金融危机：投资高盛、GE
- 2022 年加息周期：投资西方石油

**关键**：危机是机会，但要保持冷静

### 4. 投资理念进化
- 1985：从"烟蒂股"到"优质公司"
- 2011：投资 IBM（失败）
- 2016：投资苹果（成功）

**关键**：永远学习，投资理念要进化

### 5. 承认错误
- 1985：纺织业务（20 年错误）
- 2008：康菲石油（30+ 亿亏损）
- 2011-2018：IBM（10+ 亿亏损）
- 2020：航空股（50 亿亏损）

**关键**：承认错误不丢人，继续错误才丢人

### 6. 永远不要赌美国会输
- 每次危机后，美国都会恢复
- 1929、2008、2020——历史证明

**关键**：对美国经济长期乐观
