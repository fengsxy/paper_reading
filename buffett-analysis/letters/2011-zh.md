# 巴菲特 2011 年股东信（中文版）

## 致伯克希尔·哈撒韦公司股东

2011 年，我们公司的账面价值增长了 4.6%。

标普 500 指数（含分红）上涨了 2.1%。我们跑赢了市场。

这一年，我做了一个重要的决定：开始投资 IBM。很多人惊讶："巴菲特不是不投资科技股吗？"让我解释一下为什么投资 IBM，以及我的思考过程。

**（编者注：这笔投资后来失败了。2018 年，巴菲特清仓 IBM，亏损约 10+ 亿美元。）**

---

## 2011 年：开始投资 IBM

### 投资概况

**2011 年 3 月**，我开始买入 IBM 股票。

**投资金额**：约 $107 亿（分批买入）  
**买入价格**：约 $170/股  
**持股数量**：约 6400 万股  
**占 IBM 市值**：约 5.5%

### 为什么投资 IBM？

很多人惊讶："巴菲特不是不投资科技股吗？"

**我的回答**：

1. **IBM 不是传统的科技公司**
   - 它是 IT 服务公司
   - 商业模式稳定
   - 客户粘性高

2. **我理解它的业务**
   - 企业 IT 服务
   - 软件、咨询、硬件
   - 商业模式清晰

3. **有护城河**
   - 客户转换成本高
   - 品牌优势
   - 规模优势

4. **合理的估值**
   - P/E 约 12-13 倍
   - 不贵

---

## 我的思考过程

### 1. 重新思考科技股

**我一直说不投资科技股。**

为什么？因为：
- 技术变化太快
- 我不理解
- 不在我的能力圈内

**但 IBM 不同。**

为什么？

1. **稳定的商业模式**
   - 不是消费科技（iPhone、安卓）
   - 是企业 IT 服务
   - 变化慢

2. **客户粘性高**
   - 企业客户转换成本高
   - 长期合同
   - 稳定的收入

3. **我理解它**
   - 商业模式清晰
   - 不是复杂的技术
   - 在我的能力圈内

### 2. IBM 的护城河

**IBM 有护城河吗？**

**我认为有。**

1. **客户转换成本高**
   - 企业 IT 系统复杂
   - 转换成本高
   - 客户不愿意换

2. **品牌优势**
   - "没有人因为买 IBM 而被解雇"
   - 企业信任 IBM
   - 品牌价值

3. **规模优势**
   - 全球业务
   - 规模经济
   - 小公司难以竞争

### 3. 估值合理

**2011 年，IBM 的估值合理。**

- 股价：约 $170
- P/E：约 12-13 倍
- 股息率：约 2%

**不贵，合理。**

## 为什么这是一个错误？（事后反思）

**（编者注：2018 年，巴菲特清仓 IBM，亏损约 10+ 亿美元。）**

### 我错在哪里？

**回顾 2011-2018 年，我犯了几个错误：**

1. **技术变化比我想象的快**
   - 云计算兴起（AWS、Azure）
   - IBM 转型缓慢
   - 失去市场份额

2. **护城河不如我想象的强**
   - 客户转换成本高，但不是不可能
   - 云计算降低了转换成本
   - 客户开始转向 AWS、Azure

3. **管理层执行不力**
   - IBM 转型缓慢
   - 错过云计算机会
   - 收入持续下降

4. **我高估了自己的理解**
   - 我以为我理解 IBM
   - 但我低估了技术变化的速度
   - 我违反了能力圈原则

### 与苹果的对比

**2016 年，我开始投资苹果。**

**为什么苹果成功，IBM 失败？**

| IBM | 苹果 |
|-----|------|
| B2B（企业客户） | B2C（消费者） |
| 技术护城河 | 品牌护城河 |
| 技术变化快 | 品牌持久 |
| 我高估了理解 | 我真正理解 |
| 失败 | 成功 |

**关键区别**：

1. **护城河类型**
   - IBM：技术护城河（不持久）
   - 苹果：品牌护城河（持久）

2. **商业模式**
   - IBM：B2B，客户理性决策
   - 苹果：B2C，消费者情感决策

3. **我的理解**
   - IBM：我以为我理解，但我错了
   - 苹果：我真正理解（消费品公司）

## 给股东的建议

### 1. 能力圈很重要

**只投资你真正理解的东西。**

2011 年，我以为我理解 IBM。

但我错了。我高估了自己的理解。

**教训**：不要高估自己的理解。

### 2. 技术护城河不持久

**技术护城河不如品牌护城河持久。**

IBM 的护城河是技术。

但技术变化快（云计算），护城河被攻破。

**教训**：品牌护城河 > 技术护城河。

### 3. 承认错误

**没有人是完美的。**

我在 IBM 上犯了错误。

**承认错误不丢人。继续错误才丢人。**

2018 年，我清仓 IBM，承认错误。

### 4. 从错误中学习

**错误是学习的机会。**

IBM 失败教会了我：
1. 不要投资真正的科技公司
2. 技术护城河不持久
3. 品牌护城河更好
4. 不要高估自己的理解

**这些教训为我投资苹果铺平了道路。**

### 5. B2B vs B2C

**B2C 公司比 B2B 公司更好。**

为什么？

1. **品牌护城河**
   - B2C：品牌忠诚度
   - B2B：理性决策

2. **转换成本**
   - B2C：情感成本
   - B2B：经济成本（可以计算）

3. **持久性**
   - B2C：品牌持久
   - B2B：技术变化快

**苹果（B2C）成功，IBM（B2B）失败。**

## 关于科技股的反思

### 我不是反对科技

**很多人误解我，认为我反对科技。**

**这不对。**

我不是反对科技，我是反对：
1. 投资我不理解的东西
2. 技术护城河（不持久）
3. 技术变化太快的公司

### 科技公司的分类

**不是所有科技公司都一样。**

| 真正的科技公司 | 消费品科技公司 |
|-------------|--------------|
| IBM、微软、谷歌 | 苹果 |
| 技术护城河 | 品牌护城河 |
| B2B 或平台 | B2C |
| 技术变化快 | 品牌持久 |
| 我不理解 | 我理解 |

**我投资的是消费品科技公司（苹果），不是真正的科技公司（IBM）。**
