# 巴菲特 1989 年股东信（中文版）

## 致伯克希尔·哈撒韦公司股东

1989 年，我们公司的净资产增长了 44.4%，从 27 亿美元增至 39 亿美元。过去 25 年（自现任管理层接手以来），每股账面价值从 19 美元增至 4,296 美元，年复合增长率为 23.8%。

这一年，我们投资了吉列公司。让我谈谈这笔投资，以及我们为什么喜欢拥有强大品牌的消费品公司。

---

## 投资吉列：品牌的力量

### 投资概况

1989 年 7 月，我们投资了 6 亿美元购买吉列公司的可转换优先股。

**投资条款**：
- 投资金额：6 亿美元
- 投资形式：可转换优先股
- 优先股股息：8.75%/年
- 转换价格：50 美元/股

这个结构很聪明：
- **下行保护**：8.75% 固定股息
- **上行空间**：可转换为普通股

### 为什么投资吉列？

吉列是一家我们理解的企业。它拥有：

1. **强大的品牌护城河**
2. **全球市场领导地位**
3. **定价权**
4. **重复消费模式**
5. **优秀的管理层**

让我详细解释。

---

## 品牌护城河：最强的竞争优势

### 什么是护城河？

我们寻找的是拥有"护城河"的企业——那些竞争对手难以攻破的企业。

护城河可以是：
- 品牌（可口可乐、吉列）
- 成本优势（Costco）
- 网络效应（信用卡）
- 转换成本（银行）

吉列的护城河是：**品牌。**

### 吉列的品牌有多强？

想象一下：
- 全球剃须刀市场份额：60%+
- 品牌认知度：极高
- 消费者忠诚度：极强

如果你给我 100 亿美元，让我去击败吉列，我做不到。

为什么？因为品牌需要时间建立，而且一旦建立，就很难被取代。

### 品牌 = 定价权

强大的品牌意味着定价权。

吉列可以：
- 推出高端产品（Sensor、Mach3）
- 收取溢价
- 消费者愿意支付

这就是品牌的力量。

---

## "剃刀-刀片"商业模式

### 最聪明的商业模式之一

吉列的商业模式非常聪明：

1. **卖剃刀**：低价或免费
2. **卖刀片**：高价，重复购买

这个模式的天才之处在于：
- 剃刀是"入口"
- 刀片是"利润来源"
- 消费者被"锁定"

### 重复消费的力量

刀片需要重复购买：
- 每周购买
- 持续一生
- 稳定的现金流

这就是我们喜欢的商业模式：**重复消费 + 高利润率。**

### 与可口可乐的相似性

吉列和可口可乐有很多相似之处：

| 特征 | 可口可乐 | 吉列 |
|-----|---------|------|
| 品牌护城河 | ✓ | ✓ |
| 全球化 | ✓ | ✓ |
| 重复消费 | ✓ | ✓ |
| 定价权 | ✓ | ✓ |
| 高利润率 | ✓ | ✓ |
| 简单易懂 | ✓ | ✓ |

这就是为什么我们喜欢这两家公司。

## 全球化的机会

### 1989 年：世界正在改变

1989 年 11 月 9 日，柏林墙倒塌。

这标志着：
- 冷战结束
- 全球化加速
- 新兴市场开放

对吉列来说，这意味着巨大的机会。

### 新兴市场的潜力

1989 年，吉列在发达国家的市场份额已经很高。但在新兴市场：
- 中国：几乎空白
- 印度：刚开始
- 东欧：刚开放
- 拉美：增长空间大

这些市场的人口占世界的大部分。

随着这些国家经济发展，人们会：
1. 从传统剃须方式转向现代剃须刀
2. 从低端产品升级到高端产品
3. 增加消费频率

这就是吉列的增长空间。

### 全球化 + 品牌 = 巨大机会

强大的品牌 + 全球化 = 巨大的增长机会

吉列可以：
- 在新兴市场复制发达国家的成功
- 利用品牌优势
- 获得高利润率

这就是我们看到的机会。

## 管理层的重要性

### Colman Mockler：优秀的 CEO

吉列的 CEO Colman Mockler 是一位优秀的管理者。

他做了几件关键的事情：

1. **专注核心业务**
   - 剃须刀和刀片
   - 退出不相关业务
   - 聚焦优势

2. **抵制收购**
   - 1980s 多次收购企图
   - Mockler 坚持独立
   - 为股东着想

3. **投资创新**
   - 开发新产品（Sensor）
   - 保持技术领先
   - 巩固市场地位

4. **全球扩张**
   - 进入新兴市场
   - 建立全球网络
   - 长期视角

这就是我们希望看到的管理层。

### 管理层 + 好业务 = 成功

优秀的管理层很重要，但：

**好的业务 + 优秀的管理层 = 巨大成功**  
**坏的业务 + 优秀的管理层 = 失败**

吉列是好业务（品牌护城河、重复消费）+ 优秀管理层（Mockler）= 巨大成功。

纺织业务是坏业务（行业衰退）+ 优秀管理层 = 失败。

这就是为什么业务质量比管理层更重要。

## 可转换优先股的智慧

### 为什么不直接买普通股？

很多人问："为什么买可转换优先股，而不是直接买普通股？"

答案是：**风险管理。**

### 可转换优先股的优势

可转换优先股提供：

1. **下行保护**
   - 8.75% 固定股息
   - 优先清偿权
   - 如果股价下跌，我们仍有固定收益

2. **上行空间**
   - 可转换为普通股
   - 如果股价上涨，我们可以转换
   - 参与上涨

3. **税收优势**
   - 股息收入税收优惠
   - 比资本利得更有利

### 风险 vs 回报

| 投资方式 | 下行保护 | 上行空间 | 风险 |
|---------|---------|---------|------|
| 普通股 | 无 | 无限 | 高 |
| 优先股 | 有 | 无 | 低 |
| 可转换优先股 | 有 | 无限 | 中 |

可转换优先股是最好的平衡。

## 集中投资消费品龙头

### 我们的投资组合

1989 年底，我们的主要持仓：

1. **可口可乐**：35%（第一大持仓）
2. **资本城市/ABC**：20%
3. **吉列**：12%（新增）
4. **GEICO**：10%
5. **华盛顿邮报**：8%

注意到什么了吗？

**我们集中投资少数几家优秀公司。**

### 为什么集中投资？

很多人说："分散投资降低风险。"

我说：**如果你知道自己在做什么，集中投资更好。**

为什么？

1. **深入理解**
   - 集中投资迫使你深入理解
   - 分散投资让你浅尝辄止

2. **最好的想法**
   - 你最好的想法只有几个
   - 为什么要投资第 20 个最好的想法？

3. **复利效应**
   - 集中投资让复利效应最大化
   - 分散投资稀释收益

### 消费品龙头的共同特征

我们喜欢的消费品公司（可口可乐、吉列）有共同特征：

1. **品牌护城河**：难以复制
2. **全球化**：增长空间大
3. **重复消费**：稳定现金流
4. **定价权**：高利润率
5. **简单易懂**：在能力圈内

这就是我们的投资策略。

## 给股东的建议

### 1. 寻找品牌护城河

**品牌是最强的护城河之一。**

为什么？
- 难以复制（需要时间）
- 提供定价权
- 消费者忠诚度高
- 持久

寻找拥有强大品牌的公司。

### 2. 重复消费 > 一次性消费

**重复消费的商业模式更好。**

吉列的刀片、可口可乐的饮料——都是重复消费。

为什么重复消费更好？
- 稳定的现金流
- 可预测的收入
- 客户终身价值高

### 3. 全球化是机会

**寻找有全球化潜力的公司。**

1989 年，全球化刚开始加速。吉列和可口可乐都有巨大的全球化机会。

新兴市场的增长潜力巨大。

### 4. 管理层很重要，但业务更重要

**好业务 + 优秀管理层 = 巨大成功**

但如果只能选一个，选好业务。

优秀的管理层无法改变糟糕的业务（纺织业务的教训）。

但在好业务里，即使管理层平庸，公司也能做得不错。

### 5. 风险管理

**可转换优先股是聪明的投资方式。**

它提供：
- 下行保护（固定股息）
- 上行空间（可转换）

这是风险和回报的最佳平衡。

## 关于能力圈

### 我们只投资我们理解的业务

吉列的商业模式很简单：
1. 生产剃刀和刀片
2. 通过零售商销售
3. 消费者重复购买

我理解这个模式。它在我的能力圈内。

### 能力圈的边界

我不懂的东西：
- 科技股（微软、英特尔）
- 生物科技
- 复杂的金融衍生品

所以我不投资它们。

**能力圈的大小不重要。重要的是知道边界，并待在圈内。**
