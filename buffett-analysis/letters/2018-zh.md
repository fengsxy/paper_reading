## 清仓 IBM

### 投资回顾

**2011 年，我们开始投资 IBM。**

**投资金额**：约 $107 亿  
**买入价格**：约 $170/股  
**持股数量**：约 6400 万股

**2017 年，我们开始减持。**

**2018 年，我们清仓。**

### 最终结果

**2018 年，我们清仓 IBM。**

**卖出价格**：约 $120-140/股  
**亏损**：约 10+ 亿美元

**这是一个失败的投资。**

---

## 为什么失败？

### 1. 我高估了自己的理解

**2011 年，我以为我理解 IBM。**

**我认为：**
- IBM 不是传统的科技公司
- 是 IT 服务公司
- 商业模式稳定
- 客户粘性高

**但我错了。**

**我低估了技术变化的速度。**

### 2. 云计算改变了一切

**2011-2018 年，云计算兴起。**

**AWS、Azure、Google Cloud**：
- 改变了 IT 服务市场
- 降低了客户转换成本
- IBM 失去市场份额

**IBM 转型缓慢**：
- 错过云计算机会
- 收入持续下降
- 股价下跌

**我低估了云计算的影响。**

### 3. 技术护城河不持久

**我以为 IBM 有护城河：**
- 客户转换成本高
- 品牌优势
- 规模优势

**但云计算降低了转换成本。**

**客户开始转向 AWS、Azure。**

**技术护城河被攻破。**

### 4. 管理层执行不力

**IBM 管理层转型缓慢。**

**问题**：
- 错过云计算机会
- 收入持续下降（2011-2018 年下降 30%+）
- 股价下跌

**管理层没有成功转型。**

## 与苹果的对比

### 为什么苹果成功，IBM 失败？

**2016 年，我开始投资苹果。**

**2018 年，苹果是我们最成功的投资之一。**

**IBM 失败，苹果成功。为什么？**

| IBM | 苹果 |
|-----|------|
| B2B（企业客户） | B2C（消费者） |
| 技术护城河 | 品牌护城河 |
| 技术变化快 | 品牌持久 |
| 客户理性决策 | 消费者情感决策 |
| 转换成本可计算 | 转换成本高（生态系统） |
| 失败 | 成功 |

**关键区别**：

1. **护城河类型**
   - IBM：技术护城河（不持久）
   - 苹果：品牌护城河（持久）

2. **商业模式**
   - IBM：B2B，客户理性决策
   - 苹果：B2C，消费者情感决策

3. **我的理解**
   - IBM：我以为我理解，但我错了
   - 苹果：我真正理解（消费品公司）

## 从 IBM 失败中学到的教训

### 1. 不要投资真正的科技公司

**IBM 是真正的科技公司。**

**特点**：
- 技术变化快
- 护城河不持久
- 我不理解

**教训**：不要投资真正的科技公司。

### 2. 技术护城河不持久

**IBM 的护城河是技术。**

但技术变化快（云计算），护城河被攻破。

**教训**：技术护城河不如品牌护城河持久。

### 3. B2C 公司比 B2B 公司更好

**IBM 是 B2B，苹果是 B2C。**

**B2C 的优势**：
- 品牌忠诚度
- 情感决策
- 转换成本高（情感成本）

**B2B 的劣势**：
- 理性决策
- 转换成本可以计算
- 容易被替代

**教训**：B2C 公司比 B2B 公司更好。

### 4. 不要高估自己的理解

**2011 年，我以为我理解 IBM。**

**我错了。**

**教训**：不要高估自己的理解。能力圈很重要。

### 5. 及时止损

**2017 年，我开始减持 IBM。**

**2018 年，我清仓。**

**虽然亏损，但及时止损。**

**教训**：承认错误，及时止损。

**教训**：投资品牌护城河，不投资技术护城河。

### 2. B2C 公司 > B2B 公司

**苹果（B2C）成功，IBM（B2B）失败。**

**教训**：B2C 公司比 B2B 公司更好。

### 3. 不要高估自己的理解

**我以为我理解 IBM，但我错了。**

**教训**：不要高估自己的理解。能力圈很重要。
