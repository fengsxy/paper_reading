# 巴菲特 2017 年股东信（中文版）

## 致伯克希尔·哈撒韦公司股东

2017 年，我们公司的账面价值增长了 23.0%。

标普 500 指数（含分红）上涨了 21.8%。我们跑赢了市场。

这一年，我们大幅增持苹果，同时减持 IBM。这标志着我对科技股投资策略的重大调整。让我谈谈这个决策，以及我从 IBM 失败中学到的东西。

---

## 2017 年：增持苹果，减持 IBM

### 苹果投资

**2017 年，我们大幅增持苹果。**

**持仓变化**：
- 2016 年底：约 6100 万股
- 2017 年底：约 1.65 亿股
- 增持：约 1.04 亿股（+170%）
- 投资金额：约 $280 亿

**苹果成为第一大持仓**：
- 市值：约 $280 亿
- 占 Berkshire 投资组合：约 20%

### IBM 减持

**2017 年，我们大幅减持 IBM。**

**持仓变化**：
- 2016 年底：约 8100 万股
- 2017 年底：约 3700 万股
- 减持：约 4400 万股（-54%）

**2018 年，我们清仓 IBM**：
- 亏损：约 10+ 亿美元

## 为什么增持苹果？

### 1. 我终于理解了苹果

**2016 年，我开始投资苹果。**

**2017 年，我更加确信苹果是好投资。**

为什么？

**因为我终于理解了：苹果不是科技公司，是消费品公司。**

### 2. 品牌护城河

**苹果的护城河是品牌，不是技术。**

**iPhone 用户的忠诚度**：
- 留存率：90%+
- 转换成本：高（生态系统）
- 品牌忠诚度：极高

**这就像可口可乐、吉列。**

### 3. 生态系统

**苹果的生态系统是天才的设计。**

一旦你买了 iPhone：
- 你会买 iPad、Mac、Apple Watch
- 你会订阅 iCloud、Apple Music、Apple TV+
- 你被"锁定"

**转换成本极高。**

### 4. 服务业务增长

**苹果的服务业务是隐藏的宝藏。**

**2017 年**：
- 服务业务收入：约 $300 亿
- 增长率：约 20%/年
- 利润率：60%+

**服务业务的特点**：
- 重复收入
- 高利润率
- 增长快
- 稳定

**这就像吉列的刀片业务。**

### 5. 估值合理

**2017 年，苹果的估值合理。**

- 股价：约 $170（调整后）
- P/E：约 15-16 倍
- 现金：约 $2500 亿
- 回购：积极

**不便宜，但合理。**

## 为什么减持 IBM？

### 1. 我错了

**2011 年，我开始投资 IBM。**

**2017 年，我承认：我错了。**

为什么？

**因为我高估了自己对 IBM 的理解。**

### 2. 技术变化太快

**IBM 面临的挑战**：

1. **云计算兴起**
   - AWS、Azure、Google Cloud
   - IBM 转型缓慢
   - 失去市场份额

2. **收入持续下降**
   - 2011-2017 年，收入从 $1070 亿降至 $790 亿
   - 下降 26%

3. **竞争加剧**
   - 云计算降低进入壁垒
   - 客户转向 AWS、Azure

### 3. 护城河不如我想象的强

**我以为 IBM 有护城河**：
- 客户转换成本高
- 品牌优势
- 规模优势

**但现实是**：
- 云计算降低了转换成本
- 客户开始转向 AWS、Azure
- 护城河被攻破

### 4. 技术护城河 vs 品牌护城河

**IBM 的护城河是技术。**

**苹果的护城河是品牌。**

**关键区别**：
- 技术护城河：不持久（技术变化快）
- 品牌护城河：持久（品牌可以持续几十年）

**这是我从 IBM 失败中学到的最重要的一课。**

## IBM vs 苹果：对比

### 商业模式

| IBM | 苹果 |
|-----|------|
| B2B（企业客户） | B2C（消费者） |
| IT 服务、软件、硬件 | 消费电子、服务 |
| 理性决策 | 情感决策 |
| 技术护城河 | 品牌护城河 |

### 护城河

| IBM | 苹果 |
|-----|------|
| 客户转换成本（技术） | 生态系统锁定（品牌） |
| 云计算降低转换成本 | 转换成本极高 |
| 护城河被攻破 | 护城河强大 |

### 结果

| IBM | 苹果 |
|-----|------|
| 收入下降 26%（2011-2017） | 收入增长 50%+（2016-2020） |
| 股价下跌 | 股价上涨 |
| 我亏损 10+ 亿美元 | 我赚了 1000+ 亿美元 |

## 从 IBM 失败中学到的教训

### 1. 不要投资真正的科技公司

**IBM 是真正的科技公司。**

**特点**：
- 技术变化快
- 护城河不持久
- 我不理解

**教训**：不要投资真正的科技公司。

### 2. 技术护城河不持久

**IBM 的护城河是技术。**

但技术变化快（云计算），护城河被攻破。

**教训**：技术护城河不如品牌护城河持久。

### 3. B2C 公司比 B2B 公司更好

**IBM 是 B2B，苹果是 B2C。**

**B2C 的优势**：
- 品牌忠诚度
- 情感决策
- 转换成本高（情感成本）

**B2B 的劣势**：
- 理性决策
- 转换成本可以计算
- 容易被替代

**教训**：B2C 公司比 B2B 公司更好。

### 4. 不要高估自己的理解

**2011 年，我以为我理解 IBM。**

**我错了。**

**教训**：不要高估自己的理解。能力圈很重要。

### 5. 承认错误，及时止损

**2017 年，我承认错误，减持 IBM。**

**2018 年，我清仓 IBM。**

**教训**：承认错误不丢人。继续错误才丢人。

## 给股东的建议

### 1. 品牌护城河 > 技术护城河

**苹果的品牌护城河持久。**

**IBM 的技术护城河不持久。**

**教训**：投资品牌护城河，不投资技术护城河。

### 2. B2C 公司 > B2B 公司

**苹果（B2C）成功，IBM（B2B）失败。**

**教训**：B2C 公司比 B2B 公司更好。

### 3. 生态系统是新的护城河

**苹果的生态系统是天才的设计。**

- iPhone + iPad + Mac + Apple Watch
- App Store + iCloud + Apple Music
- 转换成本极高

**这是现代护城河。**

### 4. 服务业务很重要

**苹果的服务业务是隐藏的宝藏。**

- 重复收入
- 高利润率
- 增长快

**这是未来的增长引擎。**

### 5. 承认错误

**IBM 是一个错误。**

我承认，我减持，我清仓。

**教训**：承认错误不丢人。继续错误才丢人。

## 关于投资理念的进化

### 从拒绝科技股到投资苹果

**我的投资理念一直在进化。**

**1990s-2000s**：
- 拒绝科技股
- "我不懂科技"
- 错过微软、谷歌

**2011**：
- 投资 IBM
- "IBM 不是传统科技公司"
- 失败

**2016-2017**：
- 投资苹果
- "苹果不是科技公司，是消费品公司"
- 成功

### 关键洞察

**不是所有科技公司都一样。**

| 真正的科技公司 | 消费品科技公司 |
|-------------|--------------|
| IBM、微软、谷歌 | 苹果 |
| 技术护城河 | 品牌护城河 |
| B2B 或平台 | B2C |
| 技术变化快 | 品牌持久 |
| 我不理解 | 我理解 |

**我投资的是消费品科技公司，不是真正的科技公司。**

## 结语

2017 年，我们大幅增持苹果，减持 IBM。

这标志着我对科技股投资策略的重大调整：
1. 从 IBM（B2B，技术护城河）到苹果（B2C，品牌护城河）
2. 从失败到成功
3. 从错误中学习

**IBM 教会了我**：
1. 不要投资真正的科技公司
2. 技术护城河不持久
3. B2C 公司比 B2B 公司更好
4. 承认错误

**苹果证明了**：
1. 品牌护城河持久
2. 生态系统是新的护城河
3. 服务业务很重要
4. 投资理念可以进化
