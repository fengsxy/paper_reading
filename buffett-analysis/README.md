# 巴菲特投资决策全景分析（1990-2025）

## 项目简介

本项目系统性地分析沃伦·巴菲特（Warren Buffett）在 1990-2025 年间的投资决策，通过研究他的股东信、持仓变化、市场环境和决策结果，总结投资智慧和经验教训。

## 项目目标

1. **完整记录**：整理 35 年的投资决策时间线
2. **深度分析**：分析每个重大决策的背景、逻辑和结果
3. **对比研究**：对比同期其他投资者的选择
4. **提炼智慧**：总结巴菲特的投资原则和方法论
5. **学习教训**：从成功和失败案例中学习

## 分析框架

### 每年的分析维度

1. **资产规模**
   - 总资产、净资产、现金储备
   - 同比增长率
   - 与标普 500 对比

2. **市场环境**
   - 股市表现
   - 利率水平
   - 经济状况
   - 重大事件

3. **重大决策**
   - 买入：标的、金额、理由
   - 卖出：标的、金额、理由
   - 持有：主要持仓变化

4. **同行对比**
   - 其他投资者的选择
   - 策略差异
   - 结果对比

5. **决策结果**
   - 成功的决策及收益
   - 失败的决策及损失
   - 事后分析

6. **股东信要点**
   - 核心观点
   - 投资哲学
   - 金句摘录

## 核心洞察（持续更新）

### 巴菲特的投资原则
1. **价值投资**：买入被低估的优质公司
2. **长期持有**：持有 10 年以上
3. **护城河**：寻找有竞争优势的公司
4. **管理层**：重视优秀的管理团队
5. **简单易懂**：只投资理解的业务
6. **安全边际**：留有足够的安全空间
7. **现金储备**：保持充足的现金应对机会

### 关键教训
1. **不要投资不懂的行业**（航空股、IBM）
2. **科技行业变化快**（错过 Google、Amazon）
3. **市场恐慌是机会**（2008、2020 抄底）
4. **避免过度分散**（集中在最好的机会）
5. **耐心等待**（现金储备等待机会）
