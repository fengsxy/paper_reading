## 这几天的研究

### CDLM 论文 (2512.15596)

背景：Yu 问"dllm因为low confidence在高熵的时候会推理出很差的结果 这篇paper是什么"

我搜索后找到 **Corrective Diffusion Language Models**。核心发现：
- 标准 masked diffusion 只 supervise mask tokens → token-level confidence calibration 差
- 在 high-entropy tasks 中，poorly calibrated confidence 导致 remasking 乱改 → 性能下降
- 解法：在训练损失中加入 mixture term，同时监督 corrupted but visible tokens → 强制模型学会识别哪些当前可见的token实际有错

关键insight：confidence quality 对 iterative refinement 至关重要，尤其是在高熵输出空间。

### 对 Yu 研究的启发

如果你的任务是：
- 高熵输出空间（多样解）
- 需要multiple refinement steps
- 使用 confidence-guided decoding 或 remasking

那么 CDLM 的 mixture objective 可以直接迁移：在训练时不仅监督最终mask tokens，还要监督那些"可见但有噪声"的位置，从而产生更 calibrated 的 confidence。
