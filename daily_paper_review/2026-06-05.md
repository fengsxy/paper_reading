## 1. SARDI: Self-Augmenting Retrieval for Diffusion Language Models
**arXiv**: 2606.06474 | **Date**: 2026-06-04 | **ICML 2026** | Author: Paul Jünger

### Task
解决离散扩散语言模型（dLLM）在 RAG 场景下的推理效率问题：如何在保持高质量答案的同时，让 retrieval过程与并行去噪轨迹协同工作，而不是事后串行查证。

### Challenge
dLLM 的多步并行去噪本身已经计算密集。现有 RAG 方法是事后查证（generate-then-retrieve），要么在最终输出上查，要么在每个 step 都做 full retrieval，开销巨大。另一个核心问题：dLLM 每步会"丢弃"一些低置信度 token，这些 token 传统上被当作废物——但它们可能蕴含早期线索。

### Insight
#### Insight
- **被丢弃的 token 是有价值的前向信号**：低置信度 token 虽不成熟，但往往在去噪早期就暴露了 salient entities——这比最终输出更能指引 retrieval 时机
- **lookahead 不需要额外计算**：这些 token 本身就是去噪过程的副产物，复用它们做检索不需要额外 forward pass
- **动态 retrieval 应该匹配去噪的置信度演化**：不是固定节奏查，而是置信度跃升时触发检索

#### Novelty
- **丢弃 token 作为 lookahead 信号**→【低置信 token 仍有实体线索】→**动态触发 retrieval**：每步检查被丢弃 token 中的实体，在检测到新实体时触发针对性检索
- **训练-free + retriever-agnostic**→【工业部署需要灵活性】→**不修改模型，不要求 retriever 适配**，任意 dense/sparse retriever 皆可接入
- **8倍吞吐量提升**→【需要与并行去噪深度耦合】→**与去噪 schedule 协同的 retrieval timing**，在置信度跃升的关键步骤精准触发，而非均匀采样

### Potential Flaw
#### 情境局限
依赖模型在早期 step就能检测到实体。如果模型在去噪早期对实体识别能力较弱（如 domain shift 场景），lookahead 信号会很弱，retrieval 时机会被推迟，整体收益降低。

#### 数据问题
对于高度专业化、实体稀少的领域（特定法律条款、冷门科学术语），早期 token 里的实体覆盖率低，lookahead 信号不足以触发有效检索。

#### 值得挖掘的方向
**dLLM 的 early-exit + early-retrieval 联合优化**：当前是 cascade式的（先 look ahead 再检索），能否设计一个联合框架，在去噪的第一个 step 就同时做 generation 和 retrieval，让两者互相引导？这比 SARDI 更深度耦合，可能对开放域 QA 有更大提升。

### Motivation
之前的方法要么在最终输出上查（太晚，信息已经固定），要么每步都查（太贵）。既然 dLLM 的去噪轨迹本身就是 multi-turn refinement，那能不能把被丢弃的低置信 token 当作"早期线索"，在它们出现时就触发精准检索？答案是：可以，而且训练-free、retriever-agnostic，在多跳 QA 上比现有 training-free 方法高 8 倍吞吐量。

## 2. GILC: Gradient-Informed Logit Correction for Discrete Diffusion Models
**arXiv**: 2606.06303 | **Date**: 2026-06-04 | **ICML 2026** | Author: Hongkun Dou

### Task
解决离散扩散模型的可控生成问题：如何在不需要 retraining 的前提下，对任意（可微或不可微）reward function 实现稳定、可控的生成引导。

### Challenge
离散扩散模型的可控生成有两条路：(1) 需要 retraining 的 fine-tuning 方法；(2) plug-and-play 的 classifier-guided方法，但离散的 high-dimensional space 导致梯度不稳定（Jacobian 难以估计）。现有 plug-and-play 方法在不可微 reward（如 DNA 结合性、蛋白质功能）上效果差，因为无法获得梯度信号。

### Insight
#### Insight
- **pretrained denoising network 可以被"征用"为 variational proxy**：网络的去噪分布本身携带对 reward 的隐式先验，不需要额外训练就能充当梯度代理
- **绕过 Jacobian 而直接修正 logit**：梯度不稳定的根源是离散空间的高维 Jacobian，避开它而直接修正 clean prediction logits 可以实现稳定引导
- **可微/不可微 reward 的统一框架**：将 reward 视为对 logit 的偏好信号，而非对梯度的影响，这样无论 reward 是否可微都能工作

#### Novelty
- **pretrained model as variational proxy**→【需要 guidance 但梯度不可用】→**GILC 框架**：用预训练去噪网络隐式建模 reward 的 posterior，作为无需额外训练的 guidance 信号来源
- **Jacobian-free logit correction**→【高维离散空间的梯度不稳定】→**直接修正 clean prediction logits**，绕过 Jacobian 估计，实现稳定引导
- **统一处理可微/不可微 reward**→【不同 reward 需要不同方法】→**单一框架同时支持 DNA/protein/moleculer 生成**，无需针对 reward 类型定制方法

### Potential Flaw
####情境局限
依赖预训练模型的去噪分布与 target reward 空间之间存在足够的相关性。如果 reward 与预训练分布差异极大（如全新化学空间），variational proxy 的质量会显著下降，引导效果有限。

#### 数据问题
对于极度稀疏的 reward 信号（如罕见药物靶点），reward 本身的信息量不足以支撑有效的 logit correction，可能导致模式崩溃到预训练分布而非 target reward。

#### 值得挖掘的方向
**将 GILC 思想迁移到 dLLM 的 RL alignment**：dLLM 的每步去噪 logit 是否也能用类似 Jacobian-free 的方式注入 reward signal？这可能是比现有 PPO/DPO 更高效的 dLLM alignment 路线——不需要 tree search，不需要 token-level reward，只需要 block-level logit correction。

### Motivation
之前的方法要么需要 retraining（贵，不灵活），要么在离散空间里梯度估计崩溃。那能不能不估计梯度，而是直接修正 logit？用预训练的去噪分布本身作为 reward 的近似后验，直接把 reward 信号叠加到 clean prediction logits 上？答案是：可以，而且 ICML 2026录用，DNA/protein/molecule 三个 domain 都 SOTA。

## 3. SAID: Scaffold-Aware Iterative Decoding for Diffusion Language Models
**arXiv**: 2606.04974 | **Date**: 2026-06-03 | **Author**: Mingju Gao (TH-AI-Lab-PKU)

### Task
解决 dLLM 推理速度问题：如何通过更智能的计算资源分配，在保持生成质量的同时显著加速（最高9.1 倍）dLLM 的去噪过程。

### Challenge
dLLM 虽然能并行更新所有 position，但需要很多步去噪迭代才能达到高质量输出。每步的计算成本相同，但不同 token 的"难度"不同：scaffold token（决定语义骨架）需要更多步，而 detail token（填充性内容）相对可预测，用更少步就能完成。

### Insight
#### Insight
- **token难度是异质的**：自然语言中，scaffold token（主语、动词、关键实体）和 detail token（形容词、介词）的收敛速度天然不同
- **语义骨架优先**：人类写作也是先搭框架再填细节——这个直觉可以转化为"先在 scaffold token 上多步去噪建立语义结构，再在 detail token 上少步完成"
- **置信度分层是自然信号**：dLLM 每步输出的置信度天然提供了 token 难度的代理信号，不需要额外训练

#### Novelty
- **scaffold token 多步 + detail token 少步**→【token 难度异质但计算资源均等分配】→**两阶段重分配计算**：先在全部 token 上做若干步去噪找到 scaffold，再在 detail token 上减少 step 数
- **置信度驱动的动态步长分配**→【需要自动判断哪些 token 属于 scaffold】→**Confidence-Hierarchical Layered Generation (CHLG)**：低置信 token 获得额外步数，高置信 token 提前收敛
- **block-wise 适配**→【SAID 需要适配标准 block扩散架构】→**block 级重分配**，在 LLaDA-8B 和 LLaDA 1.5 上验证，最大加速 9.1 倍

### Potential Flaw
#### 情境局限
对于语义结构不清晰、scaffold 和 detail 边界模糊的文本（如诗歌、创意写作），scaffold detection效果会下降。CHLG 的置信度信号在开放域生成上可能无法可靠区分"语义关键"和"词汇丰富"两类 token。

#### 数据问题
在高度专业化的短文本（代码片段、数学公式）上，detail token 的比例低且每步信息量高，scaffold/detail 的二阶段划分可能不适用——这类场景的加速比可能远低于平均的 9.1 倍。

#### 值得挖掘的方向
**dLLM 的 adaptive step count + KV cache 联合优化**：SAID 揭示了 token 难度异质性，但还没有利用跨 step 的 KV reuse。如果把 CHLG 的置信度信号与动态 KV eviction 结合起来，可能实现"更难 token 用更多步 + 已确认 token 缓存"的双重加速，这是一个尚未被充分探索的交叉点。

### Motivation
之前的方法要么所有 token 均等分配步数（浪费计算），要么需要提前知道哪些 token 是 scaffold（需要训练或启发式规则）。既然 dLLM 每步都有置信度输出，那能不能让置信度自己告诉我们哪些 token 已经收敛了、哪些还需要更多计算？答案是：可以，scaffold 先跑多步、detail 少步，9.1 倍加速且不掉质量。

## 4. CAPR: Cached-Amortized Path Refinement for dLLM-RL
**arXiv**: 2606.04396 | **Date**: 2026-06-03 | **Author**: (dLLM-RL group)

### Task
解决 dLLM 强化学习训练中的信用分配（credit assignment）问题：如何从稀疏的最终 outcome reward 中，为 denoising trajectory 上的每个 block 分配局部训练信号，而不需要昂贵的 tree search。

### Challenge
dLLM 的 RL 有两条路：(1) flat rollouts便宜但只有整体 reward，无法做局部信用分配；(2) tree rollouts 提供细粒度信用分配，但计算代价是 flat 的数倍。denoising trace 本身蕴含了丰富的时间结构（哪些 token 在哪个 step 变得置信），但现有方法只用它做 weakly-supervised signal。

### Insight
#### Insight
- **去噪轨迹本身就是树状结构的弱近似**：每个 step 的 unmasking 过程决定了 token 的"出生顺序"，这个顺序隐含了 token重要性（越早变得置信的 token 对最终答案贡献越大）
- **cached trajectory state 可以生成廉价的 sibling continuations**：不需要真正展开 tree，只需要在已有的轨迹 state 上生成兄弟延续，就能获得类似 tree search 的局部信号
- **block-level value head 可以把稀疏 reward 转换为局部 PPO weight**：训练一个 value head 来预测每个 block 的 discounted future reward，从而将 1 个最终 reward 分解为多个局部信号

#### Novelty
- **去噪 trace → 树状监督**→【tree rollouts 太贵，flat rollouts 太粗】→**CAPR 框架**：将去噪轨迹压缩为 path state，用 cached trajectory 生成廉价兄弟延续
- **block-level value head**→【需要把1 个稀疏 reward 分配到多个 block】→**训练 value head 将 final outcome reward 转换为 block-level PPO weight**，实现局部信用分配
- **0.75x flat rollout cost, 0.6x tree rollout cost**→【需要兼顾效率和精度】→**在 4x4 Sudoku / Countdown / GSM8K / Math500 上 SOTA**，Sudoku 上以<1/3 的每步计算量达到 tree search 同等性能

### Potential Flaw
#### 情境局限
在需要细粒度 token-level 精确推理的任务（如复杂编程、严密数学证明）上，block-level 的信用分配可能仍然太粗。CAPR 的 value head 是在 block 级别做预测，如果 block 内 token 之间的重要性差异很大，block-level 均分 reward 会丢失关键信号。

#### 数据问题
对于随机性强的任务（开放域问答、多解数学题），final outcome reward 可能无法可靠反映中间 block 的贡献——即使最终答案正确，中间的推理路径也可能有问题。

#### 值得挖掘的方向
**将 CAPR 的 path state 用于 sampling 或 decoding**：当前 path state 只用于 RL training signal，但它本质上是去噪轨迹的压缩表示——能否用它来做 decoding时的 early stopping 或质量预测？这可能是 dLLM 推理阶段的一个新工具，而不仅仅是训练阶段。

### Motivation
之前的方法要么用 flat rollout（便宜但没有局部信号），要么用 tree search（有好信号但太贵）。既然去噪轨迹本身在每个 step 都在揭示 token——那能不能把这个"自然展开的树"直接当作训练信号，而不需要真正的树结构计算？答案是：可以，cached sibling + block value head 实现 0.75x flat cost 和 0.6x tree cost 的组合。

## 5. The Loss Is Not Enough: Sampling Conditions in Contrastive Representation Learning
**arXiv**: 2606.04280 | **Date**: 2026-06-02 | **Author**: Justinas Zaliaduonis

### Task
解决 contrastive learning 的理论黑箱问题：什么条件下 contrastive loss 才能恢复有意义的潜在几何结构？特别是 sampling机制（如何构造正样本对）如何影响 representation 的 identifiability。

### Challenge
Contrastive learning 的理论分析长期停留在"当正样本对足够多样时表示会变好"的直觉层面，缺乏严格的形式化。更关键的问题是：标准 full-support von Mises-Fisher 假设下的理论结论，与实际中受限的条件采样（conditional sampling）是否一致？两者之间存在理论裂缝。

### Insight
#### Insight
- **正样本对的 support diversity 是必要条件**：measure-theoretic 框架证明，正样本采样的 support 必须足够 diversity 才能实现等距恢复——这个条件之前只是隐含假设
- **restricted conditional sampling 会导致非正交映射达到更低的 asymptotic loss**：这意味着标准理论在 conditional sampling 下不成立——低 loss 不等于好表示
- **architectural inductive bias 在 sampling diversity 受限时更重要**：当正样本多样性不足时，encoder 的结构偏好成为决定表示质量的主导因素——这为近年 ViT/CNN 的架构差异提供了理论解释

#### Novelty
- **measure-theoretic diversity condition**→【正样本 support 多样性从未被严格形式化】→**提出 diversity condition**：证明 support diversity 是等距恢复的必要条件，并给出可检验的判据
- **restricted conditional sampling → non-orthogonal minimizers**→【标准理论假设 full-support】→**发现 conditional sampling 下的理论裂缝**：asymptotic loss 更低不代表等距恢复更好
- **support-corrected InfoNCE**→【需要修正 sampling 偏差导致的 identifiability 问题】→**提出修正版 InfoNCE**：在有限样本条件下恢复正交表示，但在 full-support 下不唯一确定最优解

### Potential Flaw
#### 情境局限
框架依赖已知的数据生成模型（latent space假设）。在实际应用中，我们不知道真实的数据生成模型，diversity condition 难以验证——这使得理论结果在实际中难以直接应用。

#### 数据问题
对于 inherently low-diversity 的正样本分布（如细粒度图像分类中同一类别的微小变体），即使加入 support correction，表示恢复的质量也会受到根本限制——diversity condition 本身就是一个下界。

#### 值得挖掘的方向
**将 diversity condition 引入 diffusion model 的 latent representation 学习**：当前 contrastive learning 主要用于 AR-LLM，但 diffusion model 的 latent space 结构是否也能用类似的信息论条件刻画？如果能在 diffusion 的隐空间中建立类似的 identifiability theory，可能会对 diffusion-based representation learning 有重要推动。

### Motivation
之前的方法用 InfoNCE 或类似 contrastive loss，但没人严格回答"在什么 sampling条件下 loss降低真的等于表示变好"。能不能用量词理论（measure-theoretic）严格形式化这个条件？答案是：可以，而且发现了 restricted conditional sampling 下的关键裂缝——低 loss 可能是因为模型学会了绕过 diversity 要求，而非真正恢复了语义结构。

## 6. Bayes-Sufficient Representations in Supervised Learning
**arXiv**: 2606.04045 | **Date**: 2026-06-02 | **Author**: Vasileios Sevetlidis

### Task
解决 supervised learning 中 representation learning 的理论定义问题：一个 representation 需要包含多少信息才能实现 Bayes-optimal 预测？信息量与 loss function 的关系是什么？

### Challenge
Representation learning 的目标长期被模糊地描述为"保留输入中对预测有用的信息"，但没有人严格定义：(1) "有用"是对哪个具体预测问题而言？(2) 不同 loss function 是否需要不同的表示内容？(3) representation 的 minimal requirement是什么？

### Insight
#### Insight
- **Bayes-action 是信息的决定者**：对于固定的 joint distribution 和 loss function，Bayes-optimal action 是唯一的——这个 action 决定了"相关"信息的边界
- **Bayes quotient 是核心对象**：在几乎处处唯一的 Bayes-action 情况下，Bayes quotient（映射到需要相同 Bayes-action 的输入等价类）识别了对预测真正重要的信息
- **loss function 决定了需要多少信息**：zero-one loss 只需要 Bayes class（粗糙），log loss 需要完整 predictive distribution（精细）——这统一解释了为什么不同任务需要不同的表示

#### Novelty
- **Bayes-sufficiency形式化**→【需要严格定义"有用"】→**定义 Bayes-sufficient representation**：存在某个 prediction head 能用它实现 Bayes-optimal action，并证明 sufficiency 由 Bayes quotient 决定
- **loss-dependent information requirement**→【不同 loss 需要不同信息】→**证明 zero-one / squared / Brier / log loss 各需不同粒度的表示信息**，并给出具体的 Bayes quotient 结构
- **sufficiency vs minimality 的区分**→【 sufficiency 不等于 minimality】→**提出 Bayes-minimal representation**：信息等价于 Bayes quotient 的表示才是 minimal 的，sufficiency 只要求 refines quotient

### Potential Flaw
#### 情境局限
Bayes-sufficiency 的定义依赖于已知 joint distribution $p(x, y)$。在实际中 $p$未知，只能从有限样本估计，因此 Bayes quotient本身不可得——理论框架优美但直接应用需要 distribution estimation。

#### 数据问题
对于 heavy-tailed 或 multi-modal 的 $p(x|y)$，Bayes quotient 可能非常复杂（每个输入都可能需要不同的 action），表示需要保留的信息量急剧增加。这使得 Bayes-minimal representation 可能比原始输入还要复杂。

#### 值得挖掘的方向
**Bayes-sufficiency 作为 diffusion model采样质量评估的理论工具**：当前 diffusion model 的采样质量评估缺乏统一框架。如果用 Bayes-sufficiency 来分析"diffusion 表示是否足以支持特定下游任务"，可能为 diffusion representation 的评估提供一个理论基础——不仅仅是 FID分数，而是"表示是否保留了对特定任务足够的信息"。

### Motivation
之前的方法把 representation learning 当作一个模糊的"保留有用信息"问题，但没有回答"对谁有用、什么算有用"。那能不能用 Bayes decision theory 的框架，把"有用"严格化为"足以实现 Bayes-optimal action"？答案是：可以，而且发现 loss function 本身决定了需要多少信息——zero-one loss 和 log loss 对表示的要求完全不同，这为不同任务的表示学习提供了统一理论。
