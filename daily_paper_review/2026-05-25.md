## 1. PulseCol: Periodically Refreshed Column-Sparse Attention for Accelerating Diffusion Language Models
**arXiv**: 2605.20813 | **Date**: 2026-05-20 | **Author**: Yanyi Lyu

### Task
加速 diffusion large language models (dLLMs) 的推理速度。dLLM 推理时全 self-attention 在每个去噪步重复执行（无 KV cache），计算代价极高。

### Challenge
现有 dLLM 稀疏 attention 方法依赖 block-sparse（块稀疏），只在去噪后期迭代才应用（认为那时模型对稀疏近似不敏感），导致：① 加速有限；② 细粒度稀疏模式无法复用；③ 早期迭代完全无法利用稀疏性。

### Insight
- 观察到 attention pattern 在去噪过程中逐渐演变，存在**可复用的稀疏结构**：早期步确定的 column 稀疏在后续步仍有信息量
- 块级别稀疏粒度太粗，无法捕捉细粒度 token 交互；迁移到**column 级别**（逐列）稀疏可更精确保留关键交互同时获得更高稀疏率
- 稀疏 pattern 不需要每步刷新——在少数中间步刷新即可追踪去噪过程的演变

### Novelty
- **dLLM 稀疏性从粗到细**→【column 比 block 更细粒度】→**Column-sparse attention**，而非 block-sparse
- **稀疏 pattern 跨步复用**→【去噪过程中 attention 模式平滑演变】→**Periodically refreshed**：早期步确定稀疏 pattern，后续步复用，仅在中间步刷新
- **GPU kernel 优化**→【column-sparse 特殊性】→**专用 GPU kernel** 实现端到端 1.95× 加速

### Method
在多种 context length 下验证，相比 FlashAttention 基线实现 1.95× 端到端加速，同时保持模型质量。

### Potential Flaw
- 1.95× 加速对于大 context（8K+）是否有显著意义存疑；稀疏率和质量的 trade-off 敏感性未充分分析
- Column-sparse kernel 的硬件利用率取决于稀疏率，动态刷新 frequency 的调参空间较大

### Future
与 speculation decoding 结合，或扩展到多模态 dLLM（diffusion-based image+text joint generation）的 attention 场景。

## 2. Drifting Objectives for Refining Discrete Diffusion Language Models
**arXiv**: 2605.19470 | **Date**: 2026-05-19

### Task
提升离散扩散语言模型（DDLM）在固定 NFE（number of function evaluations）下的生成质量。DDLM 通过迭代去噪分类 token 序列生成文本，核心挑战：如何在有限步数内生成高质量文本。

### Challenge
- 连续 diffusion 的 drifting 技术（通过训练时修正吸收采样时修正）不能直接迁移到离散 domain：hard token sample 不可导，categorical prediction 无法提供连续 drift 信号
- 现有方法在低 NFE（4-10步）下生成质量下降明显（Gen.-PPL 高）

### Insight
将 drifting 思想从 continuous 迁移到 discrete domain 的关键桥梁：**lift categorical predictions to soft-token features**，在 frozen semantic space 中应用 anti-symmetric drifting，再通过 stop-gradient 将结果回传到 DDLM logits。"软化" token 表示是连接离散分类与连续 drift 的必经之路。

### Novelty
- **Token 级别的 continuous drift**→【连续扩散的 anti-symmetric drift 无法直接用于离散 token】→**TokenDrift**：将 categorical prediction 提升为 soft-token feature，在 semantic space 中做 drifting
- **Stop-gradient interface**→【hard token sample 不可导】→**stop-gradient feature target**，反向传播到 logits 而非直接通过 hard sample

### Method
在 MDLM 和 DUO 两种 masked/uniform-state diffusion backbone 上验证，TokenDrift 在 4 NFE 下将 Gen.-PPL 分别降低 89% 和 86%。

### Potential Flaw
- Semantic space 的选择（如何定义"frozen semantic space"）缺乏理论依据，不同 backbone 效果可能差异大
- Stop-gradient 引入的梯度偏差在复杂任务（长文本、代码生成）中的影响未知

### Future
将 TokenDrift 与 AR 模型结合（DDLM+AR 混合生成），或扩展到 multi-modal discrete diffusion（image tokenization + text tokenization）。

## 3. Machine Unlearning for Masked Diffusion Language Models
**arXiv**: 2605.18253 | **Date**: 2026-05-18

### Task
对 Masked Diffusion Language Models (MDLM) 实现 machine unlearning：在不重新训练的情况下，让模型"遗忘"特定学到的知识，同时保持其他能力不受影响。应用场景：隐私合规（GDPR）、有害内容移除、版权内容删除。

### Challenge
MDLM（如 LLaDA、Dream）的 fine-tuning 机制与 AR-LLM 不同：学习是从 prompt-masked unconditional distribution 向 prompt-conditional distribution 迁移的过程。传统 unlearning 方法（梯度上升、元学习、SFT 定位）不能直接迁移到 diffusion paradigm。

### Insight
- Diffusion 的去噪过程天然具有 **KL divergence structure**：学习 = 最小化从 conditional 到 unconditional 的 KL
- Unlearning = 最大化 conditional prediction 与 unconditional anchor 的 KL divergence
- Temperature scaling 参数天然控制 **privacy-utility trade-off**：温度越高，遗忘越彻底但utility损失越大

### Novelty
- **KL divergence anchor 驱动 unlearning**→【MDLM 的 fine-tuning 机制本质是条件分布迁移】→**Masked Diffusion Unlearning (MDU)**：最小化 conditional prediction 到 prompt-masked unconditional anchor 的 forward KL
- **Temperature 隐私-效用权衡**→【unlearning degree 需要可控】→**Temperature scaling** 控制 privacy-utility trade-off

### Method
在标准和 MDLM backbone 上验证，MDU 在多个 benchmark 上实现有效遗忘同时保持下游任务性能。

### Potential Flaw
- 遗忘效果的评估指标（generative perplexity、knowledge probe）是否真正反映"遗忘"存疑
- 对复合遗忘（同时遗忘多个知识点）的 scaling 能力未验证

### Future
结合 representation engineering，对特定 knowledge circuit 的 activation 做定向修改，而非依赖 output space 的 KL divergence。

## 4. Understanding Data Temporality Impact on Large Language Models Pre-training
**arXiv**: 2605.22769 | **Date**: 2026-05-21

### Task
研究预训练数据的时间顺序（temporal ordering）对 LLM 获取时间敏感知识的影响。核心问题：LLM 的知识"冻结"在训练时，如何让模型更好地建立时间认知？

### Challenge
标准预训练对数据做 shuffle，知识被同质地对待，模型无法区分"2023年的事实"和"2024年的事实"。时间敏感性知识（factual freshness）在 shuffled training 下难以被精确建模，且容易被旧知识覆盖。

### Insight
**Temporal ordering > Shuffled**：顺序训练（temporally ordered Common Crawl snapshots）的模型在保持 general language understanding 的同时，展现出更 up-to-date 和 temporally precise 的知识。Shuffled 预训练反而在旧数据上峰值，可能因为旧知识的重复出现率更高。

### Novelty
- **时间结构化预训练**→【shuffled 数据无法建模时间依赖】→**Temporally ordered Common Crawl snapshots** 预训练
- **时间基准评估**→【缺乏时间感知 benchmark】→**7,000+ temporally grounded questions** benchmark，测试模型是否正确关联事实与对应时间段

### Method
预训练 6B 参数模型，在 temporally ordered vs shuffled 上对比。顺序训练模型：general 能力持平 + factual freshness 提升 + 旧知识可能被稀释（shuffled 的旧知识重复效应优势消失）。

### Potential Flaw
- 顺序训练可能导致"灾难性遗忘"——早期数据在后续训练中被稀释
- 真实世界数据分布本身有时间相关性，shuffled 训练可能是为了让模型在不同 domain 间泛化
- 评估 benchmark 依赖 time-sensitive QA，如何排除 test set contamination 的影响

### Future
结合 curriculum learning，将时间顺序扩展为多维 domain-time 联合 ordering，研究不同 ordering strategy 对 agentic capabilities 的影响。

## 5. Noise Schedule Design for Diffusion Models: An Optimal Control Perspective
**arXiv**: 2605.21911 | **Date**: 2026-05-21 | **Author**: Seo Taek Kong

### Task
为 diffusion models 系统性分析并设计 noise schedule：如何确定前向扩散过程中噪声强度随时间的分布，使得采样效率最高、生成质量最好？

### Challenge
- Cosine、linear、exponential 等 schedule 均为经验设计，缺乏统一理论
- 最优性条件不明确：为什么 cosine 在实践中有效？是否有更好的 schedule？
- 固定 NFE 下 schedule 选择对 FID 影响显著，但无法从理论预测

### Insight
- 将 **noise schedule design → optimal control problem**：state = Fisher information of diffusion process（随 ODE 演化），control = noise schedule，objective = 包含 Fisher information 的泛函（是 KL sampling error 的上界）
- 求解最优控制 → 得到 **sufficient conditions**，在什么条件下可达 SOTA 采样误差界
- 进一步参数化假设 → **闭式 noise schedule 表达式**（指数 schedule 和 sigmoid schedule 的推广）

### Novelty
- **Fisher information 最优控制框架**→【noise schedule 设计缺乏理论】→**将 schedule design 重新表述为最优控制**，Fisher information 作为 state，KL sampling error bound 作为 objective
- **闭式 schedule 推导**→【经验 schedule 无法分析最优点】→**带可调参数的 schedule 闭式表达**，可系统调参优化 FID

### Method
在 CIFAR-10、ImageNet 64×64、LSUN 上验证，新 schedule 在固定 NFES 下相比 linear/cosine 降低 FID。

### Potential Flaw
- 理论分析基于连续时间近似，实际离散步的误差累积效应未建模
- 闭式表达依赖对数据分布的参数假设（高斯混合等），真实数据可能偏离假设

### Future
与 consistency model 结合，将 schedule 优化扩展到极低步（≤5）场景；或扩展到 latent diffusion 的 latent space noise schedule。

## 6. Probabilistic Attribution For Large Language Models
**arXiv**: 2605.21726 | **Date**: 2026-05-20 | **Author**: Fnu Shilpika

### Task
为 LLM 生成过程提供**概率论语义下**的 token 级别 attribution：给定模型生成了一个 token，如何量化该 token 对最终输出的贡献？

### Challenge
- 现有 attribution 方法（attention weights、SHAP、grad norm）依赖局部梯度或激活统计，缺乏**全局概率语义**
- LLM 的生成是 stochastic process，但 attribution 往往不提供概率解释
- 不同方法给出不一致的解释，难以对比或信任

### Insight
- LLM 的生成过程本质上是一个**随机过程**（stochastic process）：每个 token 的条件概率 $p(x_t | x_{<t})$ 编码了模型在训练中学习的分布结构
- 利用 **Bayes rule** 反转 next-token log-probabilities，捕捉模型对 token 序列的内部概率表示
- Attribution score = log ratio：$p(\text{response}|\text{prompt})$ / $p(\text{response}|\text{prompt with token marginalized away)$

### Novelty
- **随机过程框架**→【LLM 生成本质是随机的】→**将 LLM 生成形式化为随机过程**，用路径空间概率度量替代传统 importance score
- **Probabilistic attribution score**→【Bayes rule 可计算 token 的条件概率效应】→**Log ratio score**，量化 marginalizing away 某 token 对整体概率的影响
- **Entropy-attribution interplay**→【高熵 token 往往最关键】→**联合分析 entropy 和 attribution**，揭示 LLM 生成的不确定性与 token 重要性的关系

### Method
8 个模型 × 7 个 prompt，测试：anomaly detection、token sensitivity、response stability、model stability、training convergence。相比 attention-based 和 gradient-based 方法在 token deletion tasks 上相关性更高。

### Potential Flaw
- Attribution 精度依赖 sampling 次数（需多次采样才能控制方差）
- 与模型内部机制的 disconnect 使其在 mechanistic interpretability 场景中不适用
- 仅验证 token deletion correlation，未在 real-world debugging 场景中验证实用性

### Future
结合 representation engineering（activation patching）做 token-level mechanistic attribution，或用于 data attribution（判断模型知识来源）。
