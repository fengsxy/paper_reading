# Daily Paper Review — 2026-05-08

**论文：** Focus on the Core: Empowering Diffusion Large Language Models by Self-Contrast
**arXiv：** [2605.01373](https://arxiv.org/abs/2605.01373)
**作者：** Jinyuan Feng et al.
**方向：** Diffusion LLM Decoding Strategy
**日期：** 2026-05-02

---

## 1. 核心问题

当前 DLLM（Diffusion Large Language Model）的解码策略未能充分利用迭代去噪提供的全局上下文建模能力——它们普遍表现出**局部偏好**，忽略了文本上下文中信息密度的不均匀分布，导致生成本的质量下降。

---

## 2. 关键发现

论文系统地研究了**高信息密度（HD）token**，得到两个重要结论：

- **显式以 HD token 为条件能显著提升输出质量**
- **HD token 具有"早收敛"特性**：它们往往比周围 token 更早稳定下来

这两个发现为后续的解码策略设计提供了基础。

---

## 3. 方法：FoCore（Focus on the Core）

核心思想是**自对比（Self-Contrast）**：

1. 在去噪过程中识别 HD token
2. 将这些 HD token **临时重新 masking 作为负样本**，引导生成
3. 这是一种**无需训练的（training-free）解码策略**

本质上是利用模型自身识别出的关键 token，通过抑制它们（当作负样本）来提升整体生成质量——类似对比学习在解码阶段的隐式应用。

此外，论文提出了加速版 **FoCore_A**：检测到 HD token 收敛后，在局部上下文窗口内并行解码稳定候选项，从而减少总解码步数。

---

## 4. 实验结果

| 实验设置 | 结果 |
|---|---|
| HumanEval pass@1（LLaDA/Dream） | 39.02 → **42.68**（CFG baseline） |
| FoCore_A 解码步数 | **减少 2.07×** |
| 单样本延迟 | 20.76s → **8.64s**（-58.4%） |
| 测试基准 | 数学、代码、逻辑推理（BOTH LLaDA 和 Dream backbone） |

结果覆盖多个主流 benchmark，**质量与效率双提升**是亮点。

---

## 5. 创新点分析

- **HD token 自对比**是最核心的创新——将对比学习的思想迁移到去噪轨迹上，用自身信息作为监督信号，无需额外训练
- **FoCore_A** 展示了"早收敛"特性可以用于自适应提前退出，是一个优雅的推理优化思路
- 方法完全 training-free，可直接集成到现有 DLLM 推理框架中

---

## 6. 个人点评

FoCore 巧妙地挖掘了 DLLM 去噪轨迹中的信息不对称性，将"哪些 token 先收敛"这一现象变成了可利用的信号。这与近期 DLM 领域多个"利用中间状态"的工作（Temporal Consistency、TReASURe 等）有相似的底层逻辑——**DLLM 的迭代性既是效率挑战，也是独特优势**，关键在于如何设计有效的轨迹级利用策略。

值得思考的方向：HD token 的定义是否依赖于特定模型？self-contrast 的强度如何自动化调节？能否结合 Process Reward Model 做更精细的引导？
