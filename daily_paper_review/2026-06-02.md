# Daily Paper Review — 2026-06-02

## 1. Task
【加速扩散语言模型（dLLM）的推理速度】——具体是将为 AR 模型设计的 token 级 speculative decoding 迁移到 dLLM 上，实现多 draft token 的单次并行验证。

## 2. Challenge
传统 speculative decoding 依赖 causal mask 保证每个生成 token 在后续位置始终处于上下文中，draft tokens 只需要一次 forward pass 就能获得所有位置的 valid logits。但 dLLM 使用 masked language modeling + bidirectional attention：mask token 指示未解决位置，有效上下文在每步 denoising 间动态变化，token 级别的时序上下文无法保持。因此标准 token 级 speculative verification 无法直接应用于 dLLM。

## 3. Insight & Novelty

### 3.1 Insight
AR speculative decoding 的核心能力来自"每个 token 在其正确 prefix 下获得 valid logit"。dLLM 无法做到这一点，根本原因在于 mask token 机制破坏了 token 级的时序上下文。但如果把 draft model 预测出的 token 作为"reference context"显式注入，并在 attention mask 上做手脚来调节这些 reference token 与当前 step token 的交互，就能重建时序有效的 token 级上下文。

### 3.2 Novelty
- **为 dLLM 重建 speculative verification 能力** → 受 AR causal mask 启发 → 引入 reference tokens + 重新设计 attention mask，使每个 token 能在单次 forward pass 中获得 valid logits
- **training-free plug-and-play** → 保留 dLLM 的并行解码优势 → 仅修改 attention mask + 拷贝少量 hidden states，可与 KV Cache、blockwise decoding 等其他加速方法灵活组合

## 4. Potential Flaw

### 4.1 情境局限
SimSD 基于 SDAR family dLLMs 实验，未在 Injet 等最新 MDLM 架构上验证；在极长上下文（>4K）或极端 block size 下的收益有待检验。

### 4.2 数据问题
当 draft model 与 target model 差异较大（如极小草稿模型），reference tokens 的质量下降，verification 接受率可能显著低于 AR speculative decoding 的场景。

### 4.3 值得挖掘的方向
**多尺度 block size + speculative 的联合优化**：BlockBatch（另一篇今日论文）已证明 block size 本身是可探索的分叉维度。将 SimSD 的 speculative verification 思想与 BlockBatch 的 block-size 分叉结合，可能实现更高效的 dLLM 推理——不同 block size 分支各自 speculative，合并时再做共识验证。

## 5. Motivation
AR 模型能对 draft tokens 做并行验证，是因为 causal mask 保证每个 token 在其 prefix 下始终 valid → dLLM 的并行优势在于多 token 同时 denoise → 但 dLLM 无法对 draft tokens 做 token 级验证 → 那能不能把 draft tokens 作为额外的 reference context 注入进来，通过修改 attention mask 让它们在当前 step 充当"已确定的 token"，从而绕过 mask token 机制的限制？
