## 1. Task
【形式化问题】

给定一个 Diffusion Language Model (DLM)，其在并行解码（parallel decoding）时，如何准确建模 token 之间的依赖关系，并在保持推理效率的前提下，缩小与自回归（AR）基线模型之间的性能差距？

具体而言：给定一个噪声序列 x_t，在 T 步去噪过程中，如何设计一个能量函数 E(x_t)，使得去噪分布 p(x_{t-1}|x_t) 能够同时纠正：
- **模型容量不足**导致的分布偏移
- **token 依赖缺失**导致的上下文不一致
- **不变性（invariance）问题**导致的采样偏差

---

## 2. Challenge
【传统方法的困境】

现有 DLM 方法在并行解码时存在三个核心问题：

**(i) 模型容量问题**：在有限步数 T 内去噪时，模型无法充分捕获所有 token 之间的交互，导致生成质量下降。

**(ii) 依赖问题（Dependency）**：传统方法假设每个 token 的去噪是条件独立的，但实际 token 之间存在长距离依赖关系。当 T 较大（即并行度更高）时，这种独立假设导致严重的分布偏移。

**(iii) 不变性问题（Invariance）**：当前 DLM 的采样过程无法保证生成的序列分布与训练分布一致，即采样分布与训练分布之间存在系统性偏移。

**核心矛盾**：增加并行度（更多 token 同时生成）会加剧上述三个问题，但降低并行度又失去了 DLM 的速度优势。

## 3. Insight & Novelty

### 3.1 Insight
- **Insight 1**：去噪过程中的"不变性"问题，本质上是因为当前的 forward process 没有对初始噪声分布做任何约束，导致采样空间与训练空间不匹配。解决思路是引入一个**能量函数**来显式约束采样分布。
- **Insight 2**：token 之间的依赖可以通过**独立能量（Ind-E）**来建模，即对每个 token 的条件分布独立建模，然后通过能量组合来纠正整体分布偏移。
- **Insight 3**：invariant energy 和 independent energy 可以统一成一个能量函数（Uni-E），且 Uni-E 可以被**精确计算**（无需 partition estimation），这解决了之前采样估计的不稳定性问题。

### 3.2 Novelty
| 解决的问题 | 启发的 Insight | 具体设计 |
|---|---|---|
| 不变性导致的采样偏移 | 能量函数约束分布的思想 | 提出 Inv-E + 采样估计器 |
| token 依赖缺失 | 独立建模每个 token 的条件分布 | 提出 Ind-E |
| 两个能量难以同时优化 | 统一能量框架 | Uni-E = Inv-E + Ind-E，且可精确计算 |
| partition estimation 的不稳定性 | 无需采样的精确推断 | Uni-E 的闭式解 |

## 4. Potential Flaw

### 4.1 情境局限
- **模型无关性（model agnostic）的代价**：Uni-E 是模型无关的，这意味着它只能利用 token 级别的统计信息，无法利用模型内部的隐藏表示。如果模型本身容量严重不足，Uni-E 的纠偏能力有限。
- **固定步数 T 的敏感性**：论文没有详细讨论 T 对 Uni-E 效果的影响。当 T 极大（极稀疏去噪步）时，Inv-E 的采样估计器可能失效。

### 4.2 数据问题
- **分布外（OOD）数据**：如果生成场景与训练数据分布差异较大（如罕见主题、专业领域），Uni-E 的能量校准可能不准确。
- **长文本生成**：当序列长度显著增加时，独立能量的线性组合可能无法捕捉全局依赖结构。

### 4.3 值得挖掘的方向
**最值得做的方向**：将 Uni-E 与 AR 模型结合，构建"混合解码"范式。

具体思路：Uni-E 可以在 AR 解码的每一步提供"全局一致性检查"，类似于在 AR 生成过程中周期性引入 DLM 的并行全局校正。这可能解锁一种新的推理范式：既保留 AR 的质量，又利用 DLM 的并行速度。

## 5. Motivation
【第一性原理思考】

**问句 1**：之前的 DLM 方法在并行解码时为什么会出现 token 间依赖丢失的问题？

答：因为传统 DLM 在去噪时假设每个 token 的生成是条件独立的（给定 x_t），但自然语言的 token 之间天然存在依赖关系。当我们并行生成多个 token 时，这种依赖被完全忽略了。

**问句 2**：那能不能在去噪过程中引入一个全局约束，让所有 token 的生成满足某种一致性？

答：这就是 Inv-E 的思想——用一个能量函数来度量当前序列的"一致性程度"，并通过能量梯度来引导去噪方向。

**问句 3**：但是，能量函数的 partition function 通常无法精确计算，需要采样估计，这又引入了新的误差。能不能避免采样估计？

答：Uni-E 的关键洞察是：当 Inv-E 和 Ind-E 联合优化时，partition function 可以被精确求解，因为两个能量的组合提供了特殊的数学结构，使得归一化常数可以闭式计算。
