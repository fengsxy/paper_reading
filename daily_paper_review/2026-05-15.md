## 1. Is Grep All You Need? How Agent Harnesses Reshape LLM Agentic Search
**arXiv**: 2605.15184 | **Date**: 2026-05-14

### Task
系统性地比较 RAG agentic search 系统中不同 retrieval strategy（BM25, dense retriever, hybrid, agentic decomposition等）对 LLM agent 复杂工作流的影响。

### Challenge
现有 RAG 研究多聚焦单跳问答，而 agentic workflows 涉及多步工具调用、迭代检索、状态管理。不同 agent harness（ReAct, Plan-and-Execute, etc.）对 retrieval 的需求不同，但缺乏系统性的联合评测。

### Insight
- Agent harness 本质上改变了检索的"粒度"——Plan-and-Execute 倾向于以子问题为单位触发检索，而 ReAct 在每步后都做检索，导致 recall/precision trade-off 不同
- 简单 grep/token-matching 在简单实体链接任务上与学习型 retriever 性能相当，但在需要推理链整合时大幅落后

### Method
构建评测 benchmark，覆盖 4 种 harness × 5 种 retrieval strategy，系统测量 task accuracy、retrieval efficiency（call count）、context quality。

### Potential Flaw
- Task 类型如果偏向 factual lookup（而非 complex reasoning），结果可能对简单 retrieval 策略过于友好
- 缺乏对 long-horizon memory 和对话上下文的评测，agentic search 的真实难点在于多轮累积的 context overflow

### Future
Retrieval 与 reasoning 的联合优化（而非分别优化后 pipeline 串联）是核心未解问题。值得探索 harness-aware retriever training。

## 2. AnyFlow: Any-Step Video Diffusion Model with On-Policy Flow Map Distillation
**arXiv**: 2605.13724 | **Date**: 2026-05-13

### Task
解决 consistency distillation 的根本限制：模型被蒸馏为 few-step 专用，增加采样步数反而质量下降。目标：构建 any-step video diffusion model，任意步数下均有 monotonic scaling 效果。

### Challenge
- Consistency distillation 把 ODE trajectory 替换为 consistency-sampling trajectory，本质上丢失了 ODE 的 test-time scaling 特性
- 之前的方法只能支持固定 few steps（如 4-8 步），无法扩展到 20-50 步
- 标准 distillation 对 long ODE trajectories 的 discretization error 积累问题无能为力

### Insight
- 关键发现：flow map transition（z_t → z_r over arbitrary interval）比 endpoint consistency mapping（z_t → z_0）更适合建模完整 ODE 行为
- Flow map 是 ODE 的微分形式，更鲁棒于步长变化，因此天然支持 any-step

### Method
1. **Flow Map Transition Learning**：优化任意时间区间内的 shortcut transitions，而非端点映射
2. **Flow Map Backward Simulation**：将完整 Euler rollout 分解为 shortcut flow-map transitions，实现高效的 on-policy distillation
3. 关键目标：减少 few-step sampling 的 discretization error 和 exposure bias

### Potential Flaw
- 实验仅限 video generation，未在 image/text diffusion上验证，可能存在 modality 依赖
- On-policy distillation 需要同时运行 teacher（full ODE）和 student（shortcut），计算开销高，训练成本是否真的优于 SD 蒸馏存疑

### Future
Flow map 的思想可能泛化到 text diffusion（如 DLM 的解码），因为 ODE 的 test-time scaling 也是 diffusion language model 的核心优势。

## 3. GroupMemBench: Benchmarking LLM Agent Memory in Multi-Party Interactions
**arXiv**: 2605.14498 | **Date**: 2026-05-14

### Task
评测 LLM agent 的 memory 系统在群组交互（多人、多角色）场景下的能力，而非传统的单用户 dyadic 对话。

### Challenge
- 现有 memory 评测和系统均针对单用户设计，忽略了多用户信息交叉、角色冲突、隐私边界等问题
- 真实部署（Slack/Teams bots、医疗团队协作）需要 agent 追踪多个并行对话的 state

### Insight
- 多方场景下，memory retrieval 的相关性判定比单用户场景更复杂：需要考虑发言者身份、时间顺序、话题相关性三个维度
- 现有 dyadic memory benchmark 对多方场景的评测结果与真实用户体验严重不符

### Method
提出 GroupMemBench，包含 multi-party conversation traces，评估 agent 对 3 类记忆的检索能力：shared facts、individual preferences、conflicting claims。

### Potential Flaw
- 合成数据可能无法完全复现真实群组交互的复杂性和噪声
- 评测维度能否涵盖真实应用中的隐私、access control 等关键需求存疑

### Future
Memory + multi-agent collaboration 是下一个重要方向。Agent 需要学会选择性遗忘（privacy-preserving memory）和选择性共享（selective context injection）。

## 4. New approaches to almost i.i.d. information theory
**arXiv**: 2605.15114 | **Date**: 2026-05-14 | **Subject**: Quantum Physics / Math Physics

### Task
对 Mazzola et al. 提出的 "almost i.i.d." 信源概念给出两种替代定义（基于 normalized quantum Wasserstein 距离；基于 average k-body marginal），并研究这三者之间的层级关系。

### Challenge
量子信息论中长期依赖 i.i.d. 假设，但实际物理系统（光子、纠缠态）无法严格满足 i.i.d.。需要更宽松但仍有理论支撑的信源模型。

### Insight
三类定义的层级严格性：Mazzola et al. 的定义最严，Wasserstein-based 次之，k-body marginal 最宽松。通过显式构造的例子证明了严格分离。

### Method
用 normalized quantum Wasserstein distance 度量信源的"非 i.i.d. 程度"，建立度量空间；k-body marginal 方法通过截断高阶关联来近似。

### Potential Flaw
- 这是纯理论工作（数学物理），缺乏实际量子通信协议的验证
- 量子 Wasserstein 距离的计算复杂度可能阻碍实际应用

### Future
与表示学习交叉：almost i.i.d. 的概念可能启发对非独立同分布数据的表示学习方法（如 non-i.i.d. representation theory），值得信息论+机器学习背景的同学关注。

## 5. Network-Aware Bilinear Tokenization for Brain Functional Connectivity
**arXiv**: 2605.14048 | **Date**: 2026-05-13

### Task
用 MAE（Masked Autoencoder）对 resting-state brain functional connectivity（FC）做自监督表示学习，但核心问题是：如何将 FC 矩阵 tokenize 以对齐大脑内在的模块化组织？

### Challenge
现有 FC tokenization 方法要么 region-centric（忽略网络结构），要么 graph-based（难以捕捉非线性交互）。需要一种既尊重脑网络模块化组织又具有表达能力的方法。

### Insight
- Bilinear tokenization 可以在保留 region-pair 交互的同时，通过网络感知采样策略优先 tokenize 跨模块的边（这些边承载更多跨模组信息）
- MAE 在 FC 上的成功说明 functional connectivity pattern 本身具有足够的结构可供重建学习

### Method
提出 Network-Aware Bilinear Tokenizer，使用图结构引导 token 的采样和 mask 策略，使 MAE 优先重建跨模块的功能连接。

### Potential Flaw
- 数据集规模有限（神经影像数据的标注成本高），自监督预训练的效果可能不稳定
- 模块化组织的 ground truth 定义依赖解剖学先验，可能存在 inter-subject variability 问题

### Future
这类方法与表示学习的交叉值得注意：MAE 在 FC 上学到的表示是否比监督学习更迁移？与 diffusion model 的结合（生成虚拟 brain FC）是潜在方向。

## 6. Learning to Optimize Radiotherapy Plans via Fluence Map Diffusion
**arXiv**: 2605.13713 | **Date**: 2026-05-13

### Task
用 diffusion model 学习 radiotherapy 中的 fluence map 优化，直接从剂量分布生成临床可行的放疗计划。

### Challenge
传统 radiotherapy planning 是耗时耗力的优化问题（需要物理师反复调试剂量约束）。Learning-based 方法需要满足复杂的临床约束（正常组织剂量上限、靶区均匀性）。

### Insight
- Diffusion model 的分布匹配特性天然适合建模"临床可行 fluence map 的流形"
- Distribution-matching distilled diffusion model 让模型只生成落在 feasible manifold 内的解，避免了传统方法需要显式约束优化的过程

### Method
基于扩散模型 one-shot 生成 fluence map，并通过 distribution matching 确保生成的 plan 满足临床约束。

### Potential Flaw
- 临床验证需要与放疗科深度合作，评估标准远超技术指标（如生存率、副作用率）
- 生成的 plan 如果在实际治疗中出现意外偏差，责任归属不清晰

### Future
Diffusion model 在科学领域的应用（分子设计、材料生成、医学成像）正在快速推进。这个方向与 Greg Ver Steeg 的 info-theoretic 方法可能有交叉点：如何用信息论工具衡量生成 plan 的质量和多样性？
