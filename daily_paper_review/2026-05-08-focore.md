## 1. Task

**问题形式化**：

当前 dLLM 的解码策略普遍存在一个问题——**局部偏好（local bias）**。具体来说：模型在每个去噪步骤中倾向于优先处理那些已经被部分去噪的 token，而忽略了上下文中信息密度不均匀的特性。

结果是：信息密度高的 token（High-Definition，HD token）没有被优先处理，导致整体生成质量下降。

**核心观察**：高信息密度 token 具有**早收敛**的特性——它们比周围 token 更早达到稳定状态。

## 3. Insight & Novelty

### 3.1 Insight

**核心发现**：高信息密度（HD）token 在去噪过程中早收敛。

> HD token 指的是那些包含关键语义信息的 token（如实体名、关键动词等）。这些 token 在去噪轨迹的早期就已经稳定下来，比周围的填充词、虚词更早进入锁定状态。

**关键实验证据**：
- 显式以 HD token 为条件，生成质量显著提升
- HD token 的收敛步数比普通 token 少 2-3 步
- 利用 HD token 的收敛信号可以实现自适应提前退出

- **具体设计**：将识别出的 HD token 临时重新 masking，作为负样本引导生成

**创新点 2**：FoCore_A——自适应提前退出

- **自适应退出的阈值**：收敛检测的阈值需要针对不同任务调优
- **代码和数学以外的领域**：只在推理、代码、逻辑任务上验证

- **Self-contrast 强度**：负样本引导的强度如何自动调节

### 4.3 值得深挖的方向

**最值得做的问题**：HD 定义是否依赖特定模型？如果 HD 的收敛特性在不同 dLLM 架构间通用，说明这是 diffusion 去噪的普遍规律，而非特定模型的 artifact。

另一个方向：FoCore 的 self-contrast 强度能否自动调节？当前是固定强度，如果能根据去噪阶段动态调整，效果可能更好。

## 5. Motivation

**General idea 推导路径**（第一性原理）：

> dLLM 的去噪轨迹有一个核心特性：**不同 token 的收敛速度不同**。
>
> 这不是偶然——信息密度高的 token（HD token）在语义层面更重要，模型需要更少的去噪步骤就能确定它们的值。
>
> 而填充词、虚词等低信息密度 token 需要更多步骤，因为它们需要依赖周围的上下文来确定。
>
> **那为什么现有解码策略没有利用这个特性？**
>
> 原因：它们只看单步置信度，没有看时间维度上的收敛行为。
>
> 一旦我们承认"不同 token 有不同的收敛速度"，最优解码策略就变成了：**优先处理 HD token，利用它们的早收敛特性做引导，并在所有 HD token 收敛后提前退出**。
>
> 这就是 FoCore 的核心思想——把去噪轨迹的时间结构变成可利用的信号，而不是被动的观察对象。

## 6. 与 H/S 假说的关联

FoCore 的 HD token 早收敛发现直接支持 H/S 地形假说：

- **HD token ≈ H 阶段**：信息密度高，早收敛，进入锁定状态
- **低密度 token ≈ S 阶段**：需要更多步，受上下文影响大

FoCore 的贡献在于：它不仅描述了这个现象，还利用它——通过识别 HD token 并利用其收敛信号来引导生成和解码退出。

这与 VSB（self-containedness）和 SWD（KL divergence = MI 下界）构成了一个完整的图景：从不同角度测量同一件事（token 是否已经进入 H 状态）。
