**论文**：Low-Cost Black-Box Detection of LLM Hallucinations via Dynamical System Prediction
**日期**：2026-05-07
**方向**：LLM / Hallucination Detection / 可信AI

---

## 1. Task

**问题形式化**：

大语言模型容易产生幻觉——生成看似合理但实际错误的内容。现有幻觉检测方法通常需要：
- 昂贵的采样或多次生成
- 依赖外部检索系统
- 需要访问模型内部激活

**目标**：用**低成本的黑盒方法**检测幻觉——只需要模型的普通输出，不需要内部激活或多次采样。

---

## 2. Challenge

| 方法 | 困境 |
|------|------|
| 基于采样的方法 | 需要多次生成，成本高 |
| 基于检索的方法 | 需要外部知识库，依赖检索质量 |
| 基于激活的方法 | 需要模型内部访问，API模型不适用 |

**根本问题**：能否只用一个模型输出就判断它是否在 hallucinate？

---

## 3. Insight & Novelty

**核心洞察**：把幻觉检测建模为**动力系统预测**问题。

> 关键思想：如果一个生成的内容是"真实的"，它的后续 token 预测应该与已生成的内容保持一致——就像一个稳定动力系统的状态转移是平滑的。
>
> 如果内容是"幻觉的"，它与已生成内容的连贯性会被破坏——就像一个不稳定动力系统的状态转移出现突变。

**创新点**：把 token 生成过程看作动力系统，用预测一致性作为幻觉信号。
- **解决的问题**：如何低成本检测幻觉
- **受启发于**：动力系统的稳定性 → 一致性 = 真实，突变 = 幻觉
- **具体设计**：不需要采样，不需要内部激活，只需要一个额外的前向传播来检查预测一致性

---

## 4. Potential Flaw

- **长文本场景**：早期 token 的幻觉可能要到很晚才能被检测到
- **事实性 vs 连贯性**：有些 hallucination 可能内部连贯但事实错误，这种情况可能漏检

---

## 5. Motivation

**General idea**：动力系统的视角为幻觉检测提供了一个全新的框架——不需要知道"正确答案是什么"，只需要知道"这个生成过程是否稳定"。这和信息论中的"收敛"概念是相通的。
