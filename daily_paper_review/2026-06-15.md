**arXiv ID**: 2606.12273

**Venue**: ACL 2026 Main Conference

**Authors**: Jia Deng, Junyi Li, Wayne Xin Zhao, Jinpeng Wang, Hongyu Lu, Ji-Rong Wen (Renmin University, CityU, Meituan, Tencent)

---

## 1. Task

形式化描述：在 Masked Diffusion Language Model (MDLM) 的后训练（post-training）阶段，如何设计训练时的 denoising order 和 token 重要性权重，使得训练动态与推理时的实际生成过程保持一致，从而提升 dLLM 在数学和代码推理任务上的表现。

具体而言，问题被分解为两个子问题：
1. **Denoising Order**：如何在每个 denoising step 确定下一个 unmask 哪些 token？
2. **Token Weighting**：在 SFT 和 RL 阶段，如何对不同 token 的损失/梯度赋予不同权重？

现有方法（diff-GRPO、wd1）采用随机 masking，忽略了 token 间由注意力结构决定的内在依赖关系。

---

## 2. Challenge

传统方法的困境：随机 masking 策略与推理时的实际生成动态存在根本性不一致。

具体问题：
- **训练-推理不匹配（Train-Inference Mismatch）**：推理时 denoiser 按固定顺序逐步 unmask token，而训练时随机 masking 产生的是一个完全不同的条件分布。模型在训练中从未见过推理时真正遇到的 partial-unmasked 状态。
- **忽略注意力结构**：全注意力 dLLM 中，token 间的依赖并非由位置顺序决定（不像自回归模型），而是由注意力交互动态涌现。随机 masking 完全忽略了这一结构信息。
- **所有 token 一视同仁**：SFT 和 RL 阶段对所有 token 赋予相同权重，但注意力分析表明不同 token 对生成稳定性有截然不同的贡献——attention-hub tokens 扮演更关键的角色。

---

## 3. Insight & Novelty

### 3.1 Insight

作者的核心洞察有两个层面：

**Insight 1（实证发现）**：dLLM 的注意力分布具有强稀疏性和时间一致性。具体而言：
- 每个 token 在整个去噪过程中持续 attend 到一小部分稳定的关键 token
- 注意力分布的稀疏性不随去噪 step 变化而显著改变
- 在推理过程中，强烈 attend 到已 denoised 上下文的 token，其生成概率稳定性显著更高

这意味着：denoising order 应该反映注意力结构——先 unmask attention-hub tokens，它们为后续 token 提供稳定的条件依赖。

**Insight 2（推理的关键 token）**：在多步推理轨迹中，部分 token（reasoning tokens）扮演特殊角色——它们强烈 attend 到上下文但被 attend 的程度较低（发出强注意力但不接收强注意力），这些 token 的正确性对整体生成质量影响最大。

### 3.2 Novelty

**创新点 1（解决问题→启发→设计）**：
随机 masking 忽略 token 依赖 → attention 稀疏且时间一致 → 用预计算的有效 attention score 确定 denoising order

具体设计：从训练好的 dLLM 中提取 attention matrices，计算每个 token 对其他 token 的平均 attention强度，据此确定 unmask 顺序——优先 unmask attention score 高的 token（即被多个其他 token 依赖的 hub tokens）。

**创新点 2（解决问题→启发→设计）**：
所有 token 损失权重相同 → attention-hub tokens 对生成稳定性贡献更大 → SFT 阶段对 attention-critical tokens 上调损失权重

具体设计：在 AGDO-SFT 中，根据 attention score 对不同 token 赋予不同权重，hub tokens 获得更高权重，使其在梯度更新中被强调。

**创新点 3（解决问题→启发→设计）**：
RL 阶段同样忽略 token 重要性 → RL 的优势在于探索，但需要引导 focus → AGDO-RL 对 attention-critical tokens 的 reward 进行加权

具体设计：在 AGDO-RL 中，reward 来自 outcome feedback（如答案正确性），但每个 token 对最终 reward 的贡献按其 attention-critical 程度加权。

## 4. Potential Flaw

### 4.1 情境局限

- **全注意力架构依赖**：AGDO 的 attention-guided order 依赖于 bidirectional attention 的完整 attention matrices。对于 linear attention 或 group attention 变体，attention 不完全捕获 token 依赖，方法可能失效。
- **静态 denoising order**：论文采用预计算的固定 denoising order，但不同类型的问题（如创意写作 vs. 数学推导）可能需要不同的 denoising 策略。固定的 order 可能无法适应任务多样性。
- **模型规模依赖**：attention 的稀疏性和时间一致性在 7B 量级上得到验证，但更小的模型（1B 以下）可能 attention 模式不够稳定，方法效果可能下降。

### 4.2 数据问题

- **复杂推理但结构单一**：数学和代码任务具有明确的推理链和结构化输出，适合 attention-hub 驱动的 denoising order。但对于开放式生成（如对话、故事），token 间依赖模式更加分散和动态，可能不利于 AGDO 的顺序设计。
- **短序列 vs. 长序列**：论文实验未披露最大序列长度。当序列极长时，attention distribution 趋近扁平，hub token 的识别变得不显著，denoising order 的优势可能消失。

### 4.3 值得挖掘的方向

**最值得写成一篇 paper 的方向**：将 AGDO 的 attention-guided denoising order 与 ADAS（Sahin et al., 2026-06-09）的 adaptive subset construction 结合。

当前 AGDO 的 denoising order 是预计算且固定的（在训练前确定），而 ADAS 提出了推理时的动态 subset selection 算法。两者都利用 attention 作为 token 依赖的代理信号，但一个用于训练阶段，一个用于推理阶段。如果能将 AGDO 的"先 unmask hub tokens"思想融入 ADAS 的动态 ranking 机制，可能解锁两者的互补优势——训练时学到的 attention 结构 + 推理时动态调整的 subset selection。

## 5. Motivation

用第一性原理回答：这个 idea 是怎么想到的？

**问句 1**：现有的 post-training 方法（如 diff-GRPO、wd1）为什么用随机 masking？效果不好的根源是什么？

答：随机 masking 简单且高效，早期方法更多关注如何让模型学会 denoise，而不是如何让训练与推理对齐。但根源在于：随机 masking 产生的条件分布与推理时逐步 unmask 的条件分布完全不同——训练时见到的分布，推理时见不到。

**问句 2**：既然要解决 train-inference mismatch，那能否直接让训练顺序与推理顺序一致？

答：这就是 Sun et al. 的 blockwise SFT 和 left-to-right order 的思路。但这些方法仍然由外部强加顺序，忽略了 dLLM 的一个关键特性：双向注意力下，token 依赖不由位置决定，而由 attention 交互动态决定。外部强加的顺序可能与注意力结构冲突。

**问句 3**：那能否从模型本身提取 token 依赖信息，用来指导 denoising order？

答：这就是 AGDO 的核心思路。dLLM 的 attention matrices 已经在训练中学会了捕获 token 间依赖关系——每个 token attend 到谁、强度多少，直接反映了对生成该 token 最重要的条件依赖。因此，从 attention 中提取的 denoising order 理论上比外部强加的顺序更贴合模型的实际工作方式。

**问句 4**：确定了 denoising order 后，为什么在 SFT 和 RL 中对不同 token 赋予不同权重？

答：因为 attention 分析表明，hub tokens（如 reasoning tokens）的正确性对整体生成质量影响更大。对这些关键 token 强调训练，可以让梯度更新更有效地改善最终输出质量。

## 📌 一句话总结

本文通过实证分析发现 dLLM 的注意力具有稀疏性和时间一致性，据此提出 AGDO：用 attention-derived 结构指导 denoising order（训练阶段）+ 对 attention-critical tokens 加权优化（SFT/RL 阶段），弥合了 dLLM 后训练中训练与推理之间的动态不一致。
