# Daily Paper Review — 2026-04-01

**Paper**: TRIMS: Trajectory-Ranked Instruction Masked Supervision for Diffusion Language Models
**arXiv ID**: 2604.00666v1
**Date**: 2026-04-01
**Tag**: dLLM / Training / Instruction Following

---

## 1. Task

**问题形式化**：

DLMs 的并行解码提供低延迟生成的潜力，但这个优势在实际中往往无法完全实现——因为：

> **Standard training does not provide explicit supervision over token reveal order**，导致 train-inference mismatch。

具体来说：标准训练只监督最终输出的 token 正确性，不监督"以什么顺序 reveal token"这个中间决策。

**目标**：提出 TRIMS（Trajectory-Ranked Instruction Masked Supervision），对去噪轨迹提供显式的排序监督。

---

## 2. Challenge

| 方法 | 困境 |
|------|------|
| Standard token-level loss | 不监督 reveal order，只监督最终正确性 |
| 启发式 reveal order | 没有利用模型自己的预测信息 |
| 不考虑 inference 的轨迹特性 | 训练和推理时的 token reveal 模式不一致 |

---

## 3. Insight & Novelty

**核心洞察**：Token reveal order 本身是一个可以被学习的信号。

> 模型在去噪过程中产生的中间预测（confidence、trajectory patterns）包含了关于"哪些 token 应该先 reveal"的信息。
>
> TRIMS 利用这些信息来训练模型，让模型学会"在推理时应该以什么顺序 reveal token"。

**创新点 1**：Trajectory-ranked supervision
- **解决的问题**：没有 reveal order 的监督
- **受启发于**：去噪轨迹中的中间预测 → 利用轨迹来监督 order
- **具体设计**：在训练时，根据 token 在轨迹中的"难度"对 masking 进行排序，让模型学会先处理简单 token

**创新点 2**：Instruction-following aligned training
- **解决的问题**：DLM 的指令跟随能力弱
- **受启发于**：指令遵循需要结构化的 reveal 顺序 → 对齐训练
- **具体设计**：在 instruction tuning 数据上应用 TRIMS，提升指令跟随能力

**创新点 3**：Training-inference consistency
- **解决的问题**：训练和推理的行为不一致
- **受启发于**：让训练时的 reveal order 接近推理时的实际使用
- **具体设计**：在训练时模拟推理时的 reveal 策略

---

## 4. Potential Flaw

- **Trajectory ranking 的质量**：如何定义"难度"可能对结果影响很大
- **只验证了 instruction following**：其他任务类型（reasoning、generation）的效果未知

---

## 5. Motivation

**General idea**：推理时模型以某种顺序 reveal token，但训练时没有显式教它"以这个顺序 reveal 是对的"。TRIMS 填补了这个空白——让训练直接监督 reveal order，消除 train-inference mismatch。
