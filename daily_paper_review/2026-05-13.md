# Daily Paper Review — 2026-05-13

## 1. ELF: Embedded Language Flows (2605.10938)
Continuous DLMs finally beating discrete ones. ELF stays in continuous embedding space until final step, uses shared-weight decoder to map to tokens. Applies Flow Matching + CFG (classifier-free guidance) directly from image domain. Key insight: image-domain techniques transfer with minimal adaptation when you operate in embedding space rather than discrete token space. Substantially outperforms both discrete and prior continuous DLMs with fewer sampling steps. Strong result — this is a clean win for the continuous camp.

## 2. LDLM: Joint Latent Space Training for Latent Diffusion Language Model (2605.07933)
Core challenge: constructing a good latent space for text. LDLM trains encoder + diffusion + decoder jointly — reshapes pre-trained LM representations via trainable encoder, yielding latents that are both easy to denoise and decode. Key trick: MSE decoder loss + diffusion-to-encoder warmup + adaptive timestep sampling + decoder-input noise. 2–13× speedup vs existing methods. Naive joint training produces low-quality diffusion — the training recipe is the contribution. Complementary to ELF: both work in continuous embedding space, but LDLM focuses on latent space construction while ELF focuses on the diffusion process itself.

## 3. Dynamic CFG via RL for Diffusion Language Models (2605.07701)
Static CFG guidance scale is suboptimal — optimal guidance varies across generation stages. This paper recasts CFG scale selection as sequential decision-making, learns dynamic guidance trajectories via PPO. Each generation step picks a discrete guidance action based on the diffusion state. Results: better controllability-quality tradeoff vs fixed-scale strategies. Policy analysis shows distinct, interpretable guidance trajectories per task. This is a natural extension of the adaptive guidance trend — and it connects to the broader theme of treating generation as planning rather than fixed sampling.

## 4. Bitstream Diffusion: Closing the AR Gap (2605.07013)
Model text as continuous diffusion over fixed-width binary bitstreams. Use matched-filter residual parameterization to separate contextual learning from analytic independent-bit posteriors. Key innovation: entropy-gated stochastic sampler — Langevin-type corrections gated by entropy-rate profile — concentrates stochasticity in high-information regions while remaining nearly deterministic elsewhere. Result: 130M param model achieves GenPPL of 59.76 at matched real-data entropy (4.31) using 256 neural function evaluations on LM1B. This is a meaningful improvement on the AR vs diffusion benchmark gap.

## 5. Cross-Modal Spectral Stabilization for Sample-Efficient Representation Learning (2605.08764)
Why deep vision models degrade in low-data regimes (e.g., medical imaging). Answer: finite-sample noise collapses the eigengap, limiting recoverable signal-bearing modes. Develops spectral theory quantifying recoverable dimension K(N) via perturbation theory + concentration bounds. Key: modes with eigenvalues above noise floor ∥Ẑ − Z∥_op ∼ √(D/N) are reliable. Multimodal learning acts as spectral stabilizer across modalities. Theoretical paper with practical implications: data efficiency in low-sample regimes is fundamentally constrained by eigenvalue decay rate, and cross-modal training helps by expanding the reliable eigenvalue region.
