# Daily Paper Review — 2026-03-17

**Paper**: DynHD: Hallucination Detection for Diffusion Large Language Models via Denoising Dynamics Deviation Learning
**arXiv ID**: 2603.16459v1
**Date**: 2026-03-17
**Tag**: dLLM / Hallucination Detection / Interpretability

---

## 1. Task

**问题形式化**：

D-LLMs（Diffusion LLMs）因其迭代精化能力成为 AR 模型的替代方案，但 **hallucination 仍然是关键问题**。

现有 hallucination detection 方法主要用 token-level uncertainty（如 entropy）作为信号，但这些方法：
1. 不直接适用于 diffusion generation（non-sequential, bidirectionally masked）
2. 忽略了 **denoising dynamics** 中包含的信息

**目标**：提出 DynHD——利用 denoising dynamics deviation 来检测 D-LLM 的 hallucination。

---

## 2. Challenge

| 方法 | 困境 |
|------|------|
| Token-level entropy | 在 D-LLM 上不直接适用，忽略了 trajectory 信息 |
| Single-pass uncertainty | 只看最终输出，不看生成过程 |
| AR hallucination detectors | 不考虑 diffusion 的迭代特性 |

---

## 3. Insight & Novelty

**核心洞察**：Hallucination 在 denoising dynamics 中有 distinctive signature。

> 关键发现：factual tokens 的 denoising trajectory 是平滑的、渐进的——它们从噪声中逐渐收敛到正确的值。
>
> Hallucinated tokens 的轨迹不同——它们可能在某个 step 快速稳定，但这个稳定点是错的；或者在多个 step 之间"漂移"（不稳定地来回跳）。
>
> 这个 trajectory deviation 是 hallucination 的强信号——比单个 step 的 entropy 更可靠。

**创新点 1**：Denoising dynamics deviation learning
- **解决的问题**：如何利用 trajectory 信息检测 hallucination
- **受启发于**：Factual vs. hallucinated tokens 的轨迹差异 → 设计 deviation metric
- **具体设计**：追踪每个 token 在整个 denoising trajectory 上的行为，计算其与"正常轨迹"的偏差

**创新点 2**：Training-free detection
- **解决的问题**：不需要额外训练
- **受启发于**：轨迹偏差可以在 inference 时直接计算
- **具体设计**：对每个 token，计算其 trajectory 的统计量（drift、variance、convergence speed），与正常阈值比较

**创新点 3**：Token-level hallucination localization
- **解决的问题**：不仅检测是否有 hallucination，还定位是哪个 token
- **受启发于**：Trajectory deviation 可以定位到具体 token
- **具体设计**：输出每个 token 的 hallucination probability

---

## 4. Potential Flaw

### 4.1 情境局限

- **需要完整的 denoising trajectory**：如果 early stopping，轨迹信息不完整
- **不同模型的正常轨迹不同**：需要为每个模型校准阈值

### 4.2 数据问题

- **Ground truth hallucination 的标注成本**：如何获得可靠的 hallucination labels
- **跨任务的可迁移性**：在某个任务上校准的阈值是否适用于其他任务

### 4.3 值得挖掘的方向

**最值得做的**：DynHD × VSB 的联合分析。

> VSB 判断 token 是否进入 self-contained 状态（不再条件于噪声）
> DynHD 判断 token 是否在 hallucinate
>
> 关键问题：一个 token 可以同时是"self-contained"（VSB say yes）但"hallucinating"（DynHD say yes）吗？
>
> 这揭示了 VSB 的局限性——self-contained 只意味着"不再条件于噪声"，不意味着"正确"。

---

## 5. Motivation

**General idea 推导路径**（第一性原理）：

> AR 模型生成 token 是顺序的——每个 token 生成时，前面的 token 已经固定，不会再变。
>
> D-LLM 不同——token 在整个 denoising 过程中一直在变化，直到最后才"稳定"。
>
> 这意味着：D-LLM 的 hallucination 不是"生成时犯错"，而是"稳定在错误值"。
>
> 关键问题是：**如何区分"正确的稳定"和"错误的稳定"？**
>
> 答案是：看轨迹。正确的 token 从噪声收敛到正确值，轨迹平滑、收敛快。错误的 token 要么过早稳定在错误值（trajectory 太短），要么在多个值之间漂移（trajectory 不稳定）。
>
> 这个轨迹信息在 AR 模型中不存在（因为 token 生成后就固定），但 D-LLM 的迭代特性让它天然可见。
