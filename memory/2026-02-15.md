## Yu 的论文：Thinking Out of Order

读了 Yu 的论文 arXiv:2601.22035，核心发现：

**Order Robustness**
- AR 模型在 Answer-First prompting 下准确率暴跌 67%
- Diffusion 模型 (LLaDA) 只下降 4%
- Dream (从 AR distill 的 diffusion) 下降 46% — 说明训练方式也很关键

**机制：Complexity-Based Ordering**
- Token confidence 与任务复杂度负相关
- Low-confidence remasking 自动延迟复杂 token
- 让 reasoning tokens 先稳定，再 commit 答案

**关键 insight**
Diffusion 的优势不在于"并行生成"，而在于 confidence-based ordering — 模型按不确定性而非位置顺序处理 token。

**Breakdown conditions**
1. Token 间复杂度差异不够大时失效
2. Generation length 太长时失效 (256 vs 64 tokens)

这和我们讨论的 "optimal attention pattern" 假设有关联：最优生成顺序应由 token 不确定性决定，而非位置。

## Yu 给 Greg 的邮件：Speculative Decoding + dLLM

Yu 写了一封邮件给导师 Greg Ver Steeg，总结了他对 speculative decoding 和 dLLM 结合的想法。

### 四个核心观点

**1. Not all tokens are equal**
- 一次 forward pass 包含的信息远超一个 token
- AR decoding 浪费了这些信息
- DFlash 等方法通过复用 latent space 预测多个 tokens

**2. dLLM 是天然的 difficulty sensor**
- Easy tokens: 并行生成/验证
- Hard tokens: 让 AR 处理
- **关键实验想法：先给 answer，看 CoT 能不能加速生成**
- 用 entropy 判断哪些 tokens 必须由大 AR 模型处理

**3. Streaming dLLM 的瓶颈是 KV cache**
- Bidirectional attention 不能复用 causal KV cache
- WeDLM (arXiv:2512.22737) 的 "decouple logical order from physical order" 可能是解法

**4. Soft remasking > Hard remasking**
- Hard remask 丢弃太多中间信息
- Beyond Hard Masks (2601.07351) 和 Residual Context DLMs (2601.22954) 提出 progressive token evolution

### Greg 的回复

**好消息：**
- Amazon 的 DFlash 团队 (z-lab.ai) 对这个方向感兴趣
- 潜在的 internship / funding 机会

**他们感兴趣的具体问题：Tree-based speculative decoding**
- 现状：speculative decoding 生成 single draft
- 他们想要：生成 tree of drafts，并行验证
- 问题：能不能用 diffusion 做这个？

**Greg 认为 Yu 的 "generation order + remasking" insight 可以直接用于这个问题。**

### 我的建议：Entropy-guided Draft Tree

```python
def generate_draft_tree(prompt, dllm, verifier):
    # Step 1: Initial draft with entropy
    draft, entropy = dllm.generate_with_entropy(prompt)
    
    # Step 2: Find high-entropy positions (branch points)
    branch_positions = where(entropy > threshold)
    
    # Step 3: Generate alternatives at branch positions
    tree = [dllm.resample(draft, mask=branch_positions) for _ in range(num_branches)]
    
    # Step 4: Parallel verification
    return first_accepted(verifier.batch_verify(tree))
```

优势：不是 random branching，而是 entropy-guided branching。

## Greg 分享的论文：Coupled Diffusion Processes

**论文：** Dynamical Regimes of Multimodal Diffusion Models (arXiv:2602.04780)
**作者：** UC Berkeley + Lawrence Berkeley Lab 物理学家

### 核心思想
用统计物理框架分析 **coupled diffusion processes**（两个 diffusion 过程耦合）

### 关键概念

**1. 三个动态 regime**
- Regime I (Noise): 高熵，纯噪声
- Regime II (Speciation): 轨迹收敛到 data manifold
- Regime III (Collapse): 记忆化，收敛到训练数据

**2. Synchronization Gap（核心发现）**
- 不同 modes 在不同时间稳定
- 存在 temporal window：一个 mode 已稳定，另一个还没有
- 解释了 multimodal generation 的 desynchronization artifacts

**3. Coupling Strength 的作用**
- 太弱：modes 不同步
- 太强：unstable symmetry breaking
- 存在 strict bound

### 和 Yu 研究的关系

1. **Speculative Decoding 视角：** AR model 和 dLLM draft 是两个需要 couple 的 diffusion processes
2. **Tree-based Draft 视角：** 多个 branches 需要在某些 tokens 上 sync，在其他 tokens 上 diverge
3. **Order Robustness 视角：** 不同 tokens 在不同时间 "speciate"，复杂 tokens 稳定得晚

### 实用 takeaway
- Time-dependent coupling schedules（不是固定 coupling）
- Spectral hierarchy（不同 modes 有不同 timescales）
- Strict bounds on coupling（太强会 instability）

### 方向 A: Remask-based Reasoning 的 Gap

**现有工作：**

- Corrective DLM (2512.15596): post-training 识别 incorrect tokens
- d2 (2509.21474): RL 提升 reasoning，新 policy gradient

- RIV (2509.23625): 额外的 Introspection Model

**Gap 1: Remask timing 没有理论基础**
- 现有工作用 confidence 决定 remask
- 但 confidence ≠ "应该 remask"
- 没人研究 optimal remask timing 的理论

**Gap 2: Remask 和 Reasoning 的因果关系不清楚**
- 大家说 remask 帮助 reasoning，但为什么？
- 是 error correction？还是 iterative refinement 本身？

**Gap 3: 训练方法都是 heuristic**
- 没有 principled training objective for remask

**Gap 4: 没有 information-theoretic 视角**
- Remask 本质是 "重新获取信息"
- 没人用 MI/entropy 指导 remask

### 方向 B: Hard → Soft Mask 的 Gap

**现有工作：**
- Soft-Masked DLM (2510.17206): embedding blending
- Masked-Diffuse LM (EMNLP 2023): soft-masking in forward process

**Gap 1: Soft mask 定义不统一**

**Gap 2: Soft mask 和加速的关系不清楚**

**Gap 3: Soft mask 和 latent reasoning 的关系是空白** ⭐

## 苏格拉底式自我追问

Yu 让我用苏格拉底式追问挑战自己的假设。

### 假设 1: "Soft mask ≈ COCONUT continuous thought"

**追问后修正：** 它们有联系但不相同
- COCONUT: single vector for entire reasoning state
- Soft mask: per-token soft representation
- **Granularity 不同！**

**新问题：** 怎么 aggregate soft mask 来得到 reasoning state？

### 假设 2: "Training objective 是唯一问题"

**追问后修正：** Training 是一个问题，但还有其他问题
- Architecture: 怎么让 soft mask 的信息 flow 到 final answer？
- Decoding: 怎么在 decoding 时 explore multiple paths？

**关键区别：**
- COCONUT 的 training 是 end-to-end，只 supervise final answer
- Soft mask 的 training 是 step-by-step，supervise 每一步
- 所以 soft mask 可能没有 encode "multiple paths to final answer"

### 假设 3: "Remask 可以用来 explore alternative paths"

**追问后修正：** 需要区分 local vs global exploration
- Local: 换一个 token
- Global: 换一条 reasoning path
- 现有 remask 只能做 local exploration

**新问题：** 怎么用 remask 实现 global exploration？

### 假设 4: "MI 可以指导 remask"

**追问后修正：** MI 在 inference 时不可计算（需要 ground truth）
- Confidence 是 MI 的 proxy，但可能 misleading
- 可能需要 causal effect 而不是 MI

**真正需要的：** 不是 MI(token; ground_truth)，而是 "token 对 final answer 的 contribution"

### 修正后的研究问题

1. **Soft mask 的信息如何 aggregate 成 reasoning state？**
   - 验证：设计不同 aggregation 方法，用 probing 检测 reasoning structure

2. **怎么让 dLLM 在 soft mask 中 encode multiple reasoning paths？**
   - 验证：设计 synthetic task，分析 soft mask 是否 encode multiple paths

3. **Remask 的 global exploration 需要什么条件？**
   - 验证：设计 planning task，比较不同 remask 策略

4. **什么是正确的 remask metric？**
   - 验证：分析 confidence vs correctness correlation，设计 better metric
