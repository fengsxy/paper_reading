## 📧 Tedium：Vibe Coding 的第一个杀手级应用——垃圾邮件

**Ernie Smith / Tedium** · [原文](https://tedium.co/2026/02/25/vibe-coded-email-spam/)

Ernie Smith 有个奇怪的爱好：他会定期翻看自己的垃圾邮件文件夹。最近他发现了一个趋势——垃圾邮件变好看了。不是"稍微好看了一点"，而是"有设计感了"。

以前的垃圾邮件一眼就能看出来：排版崩坏、图片加载不出来就是一片空白、HTML 写得像是 1998 年的 GeoCities。但现在，这些钓鱼邮件开始有了 Claude 的味道——干净的布局、合理的间距、甚至在关闭图片的情况下依然能保持结构完整（这在垃圾邮件文件夹里很关键，因为图片默认是关闭的）。

Smith 引用了 Anthropic 去年夏天的一份报告：不会写代码的人现在可以用 LLM 构建商业级勒索软件，售价高达 1200 美元一套。安全平台 Guard.io 给这个现象起了个名字：**VibeScamming**——就像 vibe coding，但目标是偷你的信用卡。

最讽刺的部分：vibe coding 做出来的正经产品和 vibe coding 做出来的钓鱼页面，长得越来越像了。同样的 chrome 风格、同样的配色、同样的 emoji 点缀。长期来看，这会反噬正经的 vibe coder——你的产品看起来和骗子的一模一样。

Smith 的安慰是：骗子虽然学会了用 AI 做好看的邮件，但依然很蠢。他最近收到一批从裸 Firebase 域名发出的垃圾邮件，一个过滤规则就全干掉了。

**吐槽：** 这篇文章揭示了 AI 民主化的一个尴尬副作用：当"做出好看的东西"不再需要技能时，"好看"就不再是信任信号了。以前你看到一封排版精美的邮件，会觉得"这公司挺正规的"。现在？可能只是某个骗子对 Claude 说了句"帮我做个假的 iCloud 存储满了的通知邮件"。设计曾经是一种门槛，现在门槛没了，我们需要新的信任锚点。Smith 建议用邮件别名和混淆——本质上是把信任从"看起来像不像真的"转移到"我有没有主动给过这个地址"。

## 🧠 Ibrahim Diallo：LLM 让知识变成了零食

**Ibrahim Diallo** · [原文](https://idiallo.com/blog/access-to-knowledge-is-no-longer-a-limitation)

这篇文章用了一个精妙的比喻：作者在桌上放了一个小盒子，把所有对 LLM 的批评都装进去，盖上盖子。然后开始列举 LLM 的好处——随时随地问任何问题、给孩子解释为什么下雨、学电池原理学到想开公司、终于能读懂叔本华了。

但写着写着，盒子自己打开了。

核心论点：LLM 消除了学习的摩擦，但摩擦本身是学习过程的一部分。他举了个例子：2022 年安倍晋三遇刺后，他花了整个假期翻 Wikipedia、日本论坛、官方文件，最终没找到一个确定的答案，但对整个事件有了深刻的理解。如果他问 ChatGPT，会得到一个"令人满意的答案"——正确、有细节、甚至会问你要不要了解更多。然后你就……去问下一个问题了。

他给孩子用 LLM 回答"十万个为什么"时发现，答案有一种"零食感"——电池、防倾杆、加州高速公路字体，像刷社交媒体一样一个接一个，什么都知道一点，什么都不深入。

最后一击："你几乎不可能发现幻觉，除非那个话题你本来就懂。等等，这是怎么回事？啊，盒子又打开了。"

**洞察：** 这篇文章让我想到 Karpathy 自己说过的一句话——他用 LLM 学新东西时，会刻意要求 LLM 不要直接给答案，而是引导他自己推导。这和 Diallo 的观察完全吻合：问题不在于 LLM 给的答案对不对，而在于"即时满足"这个交互模式本身就在破坏深度学习。ChatGPT 的对话界面天然鼓励你"问完就走"，而不是"停下来想想"。这不是 LLM 的 bug，是 chat interface 的 bug。也许我们需要的不是更好的 LLM，而是更好的学习界面——一个会故意让你慢下来、逼你自己思考的界面。讽刺的是，这恰恰是传统书籍已经做到的事。

## 🏪 Cory Doctorow：全美经济都在交 Amazon 税

**Pluralistic** · [原文](https://pluralistic.net/2026/02/25/most-favored-nation/)

Doctorow 今天的长文聚焦加州总检察长对 Amazon 的反垄断诉讼，核心是一个叫 **MFN（最惠国待遇）** 的定价机制。

逻辑链条很清晰：Amazon 向卖家收取 50-60% 的佣金 → 卖家要涨价才能活 → Amazon 不禁止涨价，但要求你在 Amazon 涨价的同时，必须在所有其他渠道也涨价 → Amazon 不需要最低价，只需要和别人一样的价 → 结果：全美所有渠道的价格都被 Amazon 的佣金推高了。

加州总检察长刚完成了对 Amazon 内部文件的分析，这些通过 discovery 程序获得的备忘录证实了这个公开的秘密。这不是 Amazon 独创的——Biden 时期 FTC 起诉过 Pepsi 和 Walmart 的类似操作（Walmart 涨价时，Pepsi 强制其他零售商涨更多），但 Trump 的 FTC 撤了案。

为什么消费者"用脚投票"没用？因为 90% 以上的富裕家庭是 Prime 会员，而底层 90% 的美国人越来越买不起东西（K 型复苏：富人恢复，穷人更穷）。卖家的选择是：在 Amazon 上被抽 60%，或者不在 Amazon 上卖——但不在 Amazon 上卖就等于放弃了唯一还有购买力的客群。

**吐槽：** 这篇文章和 AI/tech 的直接关系不大，但 MFN 定价机制的逻辑对做平台的人很有启发。本质上 Amazon 做的事情是：我不需要比你便宜，我只需要确保你不能比我便宜。这和很多 SaaS 平台的定价策略异曲同工。另外，"discovery 程序获得的内部备忘录"这个细节值得注意——在美国打反垄断官司，真正的武器不是经济学理论，而是对方自己写的内部邮件。
