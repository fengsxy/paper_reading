### Simon Willison 用 HN 评论画像用户：隐私的公开悖论

**[Simon Willison](https://simonwillison.net/2026/Mar/21/profiling-hacker-news-users/#atom-everything)** - 2026-03-21 23:59

Simon 分享了一个"轻度反乌托邦"实验：用 Algolia API 抓取任意 HN 用户最近 1000 条评论，然后丢给 Claude Opus 4.6 说"画像此用户"。结果惊人地精确——职业身份、技术偏好、性格特征、甚至个人爱好都被还原。他公开了自己的画像结果作为示例，一切都准确无误。他用这个工具主要是判断对方是否在恶意争论，但也承认"即使信息是公开自愿发布的，被如此轻松地拼出完整画像仍然令人不安"。

**点评**：对做 NLP/隐私研究的人来说这是个极好的案例——公开数据 + LLM 聚合能力 = 事实上的去匿名化。值得 Yu 在 Trustworthy AI 方向留意。
