# Analysis: EP3

## 0. 3-5 句摘要

这期核心是“从研究者到 CEO 的能力迁移”。胡渊鸣给出的观点很直接：创业不是把学术成果搬到公司，而是每个阶段都要重做角色定义。Taichi 到 Meshy 的路径说明，技术正确不代表商业自动成立，必须在产品化和组织能力上同步升级。节目最有价值的是把开源、商业化、团队管理放到一个统一决策框架下讨论，而不是分割叙事。

## 1. 反共识/非显然观点

- 开源短期不赚钱，但对人才吸引和生态势能有长期复利。
- CEO 的核心不是“让大家喜欢”，而是为整体最优做困难决策。
- 纯 synthetic data 路线存在边界，必须与真实反馈闭环配合。

## 2. 可学习的点（可迁移的方法论）

- 每 3-6 个月做一次“角色重构复盘”：当前能力是否匹配当前阶段。
- 技术路线评估同时看三件事：可行性、可交付性、可持续性。
- 把开源看成战略资产：不仅是代码公开，更是叙事与人才机制。
- 在转型期先保住核心节奏（交付/现金流/人才稳定），再扩战线。

## 3. 提问技巧（采访方法）

- 开场先问“你是谁”，把后续问题锚定在价值观上。
- 通过“转型拐点”追问，能快速提炼可迁移决策框架。
- 在理念与业务数据之间来回切换，避免访谈变成纯鸡汤。

## 4. 可进一步验证/挖坑

- Meshy 增长中的关键驱动是产品能力、渠道还是生态协同？
- 研究型团队转商业团队时，最常见失败模式是什么？
- 物理仿真在 3D 生成里的边际价值可否标准化度量？
