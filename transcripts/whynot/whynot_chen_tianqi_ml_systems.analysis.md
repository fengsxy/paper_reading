# Analysis: EP2

## 0. 3-5 句摘要

这期把陈天奇过去十多年做系统的主线讲得非常清楚：从 XGBoost 到 MXNet，再到 TVM/MLC LLM，本质都是在做“模型能力到真实可用能力”的转换器。他给出的长期主义不是坚持原路径，而是当范式变化时主动重构路线。节目里最硬核的启发不是某个技术细节，而是“现实约束中的理想实现”：既不空谈愿景，也不只做局部优化。对做研究和做产品的人来说，这是一套可迁移的决策框架。

## 1. 反共识/非显然观点

- 反共识 1：做重要问题和做平庸问题耗时差不多，真正稀缺的是押注方向的勇气。
- 反共识 2：长期主义不等于路径依赖，关键时刻必须允许推翻自己。
- 反共识 3：开源价值不止于传播，而是长期的人才和生态杠杆。

## 2. 可学习的点（可迁移的方法论）

- 用“3 年后仍成立吗”筛选技术路线，避免短期噪声驱动。
- 把“部署反馈”纳入研究输入，而不是把研究与工程割裂。
- 在组织层面预留重构能力：技术、团队分工、产品边界都应可演化。
- 对关键路线做 A/B 预案，降低单一路线失效时的系统性风险。

## 3. 提问技巧（采访方法）

- 从项目时间线入手，降低听众理解门槛，再拉高到价值观层面。
- 把“技术节点”与“人生节点”交叉提问，可获得更高信息密度。
- 通过失败时刻追问决策逻辑，比追问成功经验更有迁移价值。

## 4. 可进一步验证/挖坑

- TVM/MLC LLM 在端侧场景中的最新真实成本曲线如何？
- 开源项目商业化后，社区治理与产品路线冲突如何平衡？
- 在当前大模型周期里，系统优化的边际收益是否重新上升？
