# Analysis: EP2

## 0. 3-5 句摘要

这期围绕陈天奇在 XGBoost、MXNet、TVM、MLC LLM 等项目中的共同主线：让机器学习系统更可部署、更可演化。
他强调长期主义不是死守旧路线，而是在关键节点敢于自我重构。
从科研到创业再到教职，他反复提到“现实约束中的理想落地”，这比单点技术更决定成败。
节目最有价值的部分是把技术路线、组织选择和个人价值观放在同一框架下讨论。


## 1. 反共识/非显然观点

- 重要问题与平庸问题耗时接近，应该优先押注重要问题。
- 真正的长期主义包含“定期推翻自己”，而不是路径依赖。
- 开源不只是传播手段，也是人才与生态的复利机制。


## 2. 可学习的点（可迁移的方法论）

- 技术选型前先问：这条路线 2-3 年后是否仍有增量空间。
- 建立“可替换架构”心态：允许核心组件被下一代方案替代。
- 研究与工程并重：用部署反馈反哺研究问题定义。


## 3. 提问技巧（采访方法）

- 先按时间线梳理，再逐个拆项目，方便听众建立连续认知。
- 把“技术决定”与“人生决定”交叉提问，信息密度更高。
- 通过失败节点追问，能更快得到可迁移经验。


## 4. 可进一步验证/挖坑

- TVM/MLC LLM 在端侧部署的最新真实成本曲线如何？
- 开源项目进入商业化后，社区治理的关键分水岭是什么？
- 在大模型时代，系统优化还能提供多大边际收益？
