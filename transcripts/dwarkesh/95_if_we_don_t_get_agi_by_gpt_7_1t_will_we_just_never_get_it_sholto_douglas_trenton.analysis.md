# Analysis: If we don't get AGI by GPT-7 (~$1T), will we just never get it? – Sholto Douglas & Trenton Bricken

## 0. 3-5 句摘要

Sholto Douglas 和 Trenton Bricken 讨论了"AGI 窄窗口"假说：如果每代模型需要增加两个数量级的计算量，那么到 GPT-7（约1万亿美元训练成本）时，如果还没有实现 AGI，我们可能永远无法实现——因为再往上就需要消耗经济体的显著比例。Douglas 认为每个数量级的计算增长带来的能力提升是递减的（更多的是可靠性的"九"而非全新能力），但即使是递减的提升也足以解锁 agent 等变革性应用。Bricken 则指出人脑有30-300万亿突触而 GPT-4 可能只有1万亿参数，暗示算法效率的巨大提升空间——即使计算量到顶，更好的算法也可能突破瓶颈。

## 1. 反共识/非显然观点

- **[00:38] 能力提升是亚线性的**：每个数量级的计算增长带来的推理能力提升不是线性的，而是亚线性的——更多的是在已有能力上增加可靠性的"九"，而非解锁全新的能力类型。这是对"scaling 万能论"的重要修正。
- **[01:13] 递减回报实际上是看空信号**：如果能力提升递减而成本指数增长，那么 GPT-4.5 和 GPT-5 的经济影响可能不如预期——这与市场的乐观预期形成对比。
- **[03:16] 算法开销极高意味着计算量到顶不等于能力到顶**：人脑比当前模型的"参数效率"高出1-2个数量级，这意味着即使无法继续扩大计算量，更好的训练算法也可能带来巨大的能力提升。
- **[04:13] 更大的模型自动变得更数据高效**：原始 scaling laws 论文就显示了这一点——模型越大，每个训练样本的学习效率越高。这可能自然解决"数据墙"问题。

## 2. 关键洞察

- "窄窗口"假说的核心逻辑：$100M → $1B → $10B → $100B → $1T，每步都在私营公司可承受范围内，但再往上就需要国家级投入。我们大约还有4-5个数量级的"跳跃"机会
- GPT-3.5 到 GPT-4 的跳跃是"从不太聪明到非常聪明"，但下一个同等跳跃可能是"从非常聪明到极其可靠"——这在经济价值上可能更大（agent 需要可靠性而非天才）
- Sam Altman 试图筹集7万亿美元本身就是在为"窗口之外"的计算量做准备——这暗示 OpenAI 内部可能已经看到了 scaling 的天花板

## 3. Takeaway

- AGI 的实现可能有一个有限的时间窗口——如果当前的 scaling 范式在5-7年内没有突破到 AGI，我们可能需要根本性的算法创新而非更多计算量
- 可靠性的提升可能比原始能力的提升更有经济价值——一个99.9%可靠的"聪明"模型比一个90%可靠的"天才"模型更有用
