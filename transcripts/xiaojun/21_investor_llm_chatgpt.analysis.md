# 访谈分析笔记

## 摘要
1. 孟秋是青松资本创始合伙人、前百度技术副总裁（管搜索产品技术），从一级市场投资人+技术老兵双重视角解读2023年AI大模型浪潮。
2. 核心判断：AI这一波有solid的长期价值支撑（不同于元宇宙泡沫），但短期估值有泡沫；大模型仍是大厂的菜，创业公司机会在垂直领域模型（数据壁垒+行业knowhow深的领域）。
3. ChatGPT不会替代搜索引擎——生成式AI的随机因子是feature不是bug，它追求的是"生成"而非"准确答案"，与搜索引擎满足的用户意图本质不同。
4. 中国VC的真实状态：都在积极看AI，但出手并不active——"划掉不该投的很容易，说什么该投现在没有答案"。谨慎乐观是主流态度。
5. 涌现不神秘——神经网络本身就是模拟大脑，灌入互联网所有公开数据后产生意外能力，逻辑推理能力可能来自学习代码（人类逻辑的极大成者）。

## 反共识/非显然观点
1. "终端用户可感知"才是技术爆发的充要条件——不是GPT-4而是ChatGPT引爆了AI浪潮，就像不是触屏技术而是iPhone引爆了移动互联网。技术再牛逼，2B就爆发不了。
2. 微软投OpenAI比OpenAI本身更牛逼——"make这个decision更牛逼"，因为当时没人相信暴力美学能走通，微软的判断力被低估了。
3. AI这一代的killer app可能不是独立入口——可能是已有大app结合AI能力就够了，不一定会出现新巨头。"它也可以不出现。"
4. 中国SaaS落地不了不是SaaS不好，是"土地不平整"——企业连数据化都没实现，用不起来AI。这个基础设施差距比技术差距更致命。
5. Prompt Engineering是过渡态——就像早期搜索引擎需要"善用搜索100条技巧"，技术成熟后自然消失。
6. 每天都有AI新闻反而说明产业还在早期——真正成熟的产业不会每天制造段子。

## 可学习的点
1. **技术浪潮的时间节奏分析法**：对比搜索引擎（PageRank→广告模式，间隔3-4年）、移动互联网（iPhone→App Store生态），推演AI的killer app时间窗口。
2. **"划掉法"投资决策**：在不确定性极高的领域，先明确什么不投（大模型伸手就能做的垂直场景、文生文类Jasper模式），再等待正面信号。
3. **垂直领域模型的投资标准**：数据是否private（如医疗病例）、行业knowhow是否足够深、大模型是否能cover——三个条件同时满足才有壁垒。
4. **"谨慎积极"的心态管理**：每天兴奋地学习但不急于出手，"iPhone4时刻到了大家再一窝蜂也不迟"。

## 提问技巧
1. **Catch-up框架**：与第一集嘉宾重聚，用"上次聊的时候vs现在"的时间对比制造叙事张力。
2. **投资人视角切入技术话题**：不问"技术怎么实现"，而问"投资机会在哪"——让技术讨论落地到商业判断。
3. **情绪温度计**：反复追问"市场真实水温"、"VC三类（激进/保守/焦虑）"——用情绪描写让抽象的市场状态变得可感知。
4. **声明时效性**："观念随之也在快速迭代，这次的声音只能代表当下的一个截取片段"——为快速变化的领域设置合理预期。

## 可进一步验证/挖坑
1. 孟秋"百度一定能做成国内最好的大模型之一"的判断——2024-2025年是否验证？文心一言的市场表现？
2. "AI不会重塑TMT巨头格局"的判断——字节、腾讯、阿里在AI上的投入和成果对比？
3. 垂直领域大模型的实际案例——医疗、材料科学（声势科技DPA1）等领域是否跑出了有壁垒的公司？
4. "中国至少会有两到三家大模型"——实际格局是否如此？还是更多/更少？
5. Prompt Engineering是否真的消失了？还是演化成了新的形态（如Agent编排）？
