# 访谈分析笔记

> 注意：本集实际内容与标题不完全一致。标题提到李志飞，但实际内容是谢青池分享"非技术出身产品经理如何系统读AI论文"的深度技术科普，涵盖从GPU到Transformer的完整深度学习论文脉络。

## 摘要
1. 谢青池是美团光年之外的产品负责人，非技术出身但用一年多时间自学读了200+篇AI论文，从完全不懂到系统入门。
2. 分享框架三个视角：历史脉络（论文的时代背景和问题驱动）、范式变迁（旧范式危机→新范式崛起）、人物故事（作者的学术生涯和产业影响）。
3. 论文脉络：Brook for GPU (2004, GPU可编程化) → AlexNet (2012, 深度学习开端) → Seq2Seq + Attention (2014, 序列建模+注意力机制) → Knowledge Distillation (2015, 模型压缩)。
4. 核心洞察：深度学习的每次突破都是同时scale了数据、计算量和模型规模——AlexNet是第一个同时scale三者的工作。
5. 推荐了系统性学习AI的完整资源清单：视频（吴恩达、李宏毅、Andrej Karpathy、李沐、3Blue1Brown）和书籍（动手学深度学习、深度学习中的数学）。

## 反共识/非显然观点
1. 产品经理读论文不是"不务正业"——了解技术边界是产品经理的底层能力，AI时代技术还在早期，必须通过读论文来follow边界演进。
2. 互联网时代不需要读技术论文，AI时代需要——因为互联网是成熟技术的应用，AI技术还在早期，边界在快速变化。
3. 读论文最难的不是单点理解，而是"不知道为什么要这么做"——缺乏历史背景导致无法理解作者的问题意识和动机。
4. Ian Buck（Brook/CUDA创始人）的导师Pat Hanrahan横跨产学研三界：图灵奖得主+Pixar创始员工+三次奥斯卡+Tableau创始人（被Salesforce以157亿美元收购）。
5. 于凯老师对Ilya的第一印象是"最差的"——觉得他夸夸其谈；反而觉得Alex最靠谱，因为"别人搞不定GPU他可以搞定"。

## 可学习的点
1. **用AI学AI**：沉浸式翻译解决英文阅读障碍、用多个LLM交叉验证学术问题、用Claude Artifacts做可视化理解原理。
2. **论文阅读方法论**：先补数学基础（线性代数、概率论）→看入门视频→按历史脉络读论文→用AI辅助理解。
3. **范式变迁的识别模式**：旧范式做到极致（如ImageNet手工特征提取）→新范式从边缘崛起（神经网络）→同时scale数据+算力+模型→新范式碾压旧范式。
4. **Encoder-Decoder结构的复兴**：70-80年代发明，2014年被Seq2Seq论文复兴，至今仍是Transformer和Diffusion的核心架构。
5. **注意力机制的本质**：给神经网络一种能力，让它能对序列间词与词的关系进行建模，解决长序列信息丢失问题。

## 提问技巧
1. **非技术人视角切入技术话题**：让产品经理而非研究员来讲论文，天然降低了听众门槛。
2. **PPT+音频双轨**：准备详尽PPT放在B站，音频版在播客平台——多平台分发，不同媒介互补。
3. **人物八卦串联技术史**：Ian Buck的导师拿了图灵奖和奥斯卡、于凯老师对Ilya的差评——让枯燥的技术史变得有趣。
