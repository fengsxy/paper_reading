# EP44: 44. 谈诺贝尔经济奖与消失在黄金阶梯上的女人

2. 许多杰出女性经济学家的贡献被低估或归功于男性合作者
3. 学术界的黄金阶梯效应：女性在每个晋升节点都面临更高的流失率
4. 改变现状需要制度性变革，而非仅靠个体努力

## Takeaway
