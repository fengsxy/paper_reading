# Analysis: EP127 - AI War / 两大联盟 / Online Learning

## 0. 3-5 句摘要

1. 广密把“AI 泡沫”改写成“AI 战争/军备竞赛”：对科技巨头与中美国家战略都是“输不起”的竞赛，因此参与者可能砸光最后一分钱也不下牌桌（ref: 04:47; 05:05）。
2. 他认为 Agent 会重做流量分配：当模型成为入口，云厂商被白牌化，Super App 与信息中介平台依赖的信息不对称会被短路，抽成结构面临压缩（ref: 05:27; 05:51）。
3. 他把全球竞争简化为“两大阵营”：Google（TPU/端到端集成，像 AI 时代的苹果） vs 英伟达生态（GPU，像 AI 时代的安卓，OpenAI/Anthropic 是优等生），并判断未来一段时间仍会“交替领先”（ref: 15:20; 15:54）。
4. “泡沫导火索”来自 OpenAI 的超大规模算力承诺（1.4T/30GW），短期账面难算，但他认为现金流与融资短期并无迫切风险，大头投入在 2028 之后（ref: 06:45; 07:35）。
5. 他把第三范式押注在 Online/Continual Learning：边推理交互边学习，可能是“核弹/核聚变级别”的突破，并在机器人领域强调“数据”是最重要的差异化筹码（ref: 04:07; 37:20; 01:00:10）。

## 1. 反共识/非显然观点

1. 这轮不是典型的泡沫周期，而更像战争：因为颠覆性太强，巨头既要防守又要进攻，退出意味着输掉未来入口（ref: 04:47; 06:12）。
2. “先选模型、再选云”会让云厂商白牌化：开发/部署的首选从 AWS/Edge 变成 GPT/Claude/Gemini，云的差异化被下沉（ref: 05:19; 05:31）。
3. Super App 的利润来自信息不对称；一旦 Agent 让分发更对称，中介平台（出行/旅行/搜索）就“不该赚那么多钱”（ref: 05:49; 06:10）。
4. 全球 AI 生态的主线可被硬件阵营化：Google 的端到端集成更像苹果，英伟达生态更像安卓，这会长期塑造产业分工与机会分布（ref: 15:31; 15:54）。
5. 在现有范式（预训练 + 强化学习）下，领先者彼此很难甩开：knowhow、人才与信息流动导致“明牌竞争”，交替领先将成为常态（ref: 36:43; 20:23）。
6. “小幅领先 -> 巨额溢价”会长期存在：最领先三家模型拿走绝大多数 AI-native 收入，领先 3%-10% 就能放大成商业差距（ref: 19:21; 19:45）。
7. OpenAI 的巨额资本开支承诺短期算不过账，但这并不必然等价于现金流危机：短期融资与账期结构可以把压力后移（ref: 07:21; 07:35）。
8. 一个暴论：机器人世界模型/多模态等可能很多是假问题，Online Learning 可能才是“唯一重要的真问题”，因为它决定泛化能力（ref: 39:52; 40:12）。
9. 机器人竞争的关键不是“谁讲故事更大”，而是“谁有更好的数据与采集方式”；真机数据集规模会成为差异化核心（ref: 01:00:07; 01:00:32）。
10. 机器人离“GPT-4 时刻”仍远：当前可能只是 GPT-0.5 到 GPT-1，架构/数据/方法尚未收敛，早期会天然分化（ref: 01:04:35; 01:04:43）。

## 2. 可学习的点（可迁移的方法论）

1. **把行业周期改写成激励一致的叙事**：用“战争/军备竞赛”解释为什么资本与巨头不会轻易停火，从而更好地制定长期策略（ref: 04:47; 05:02）。
2. **用“入口变化”推演二级影响**：从 Agent 成为流量入口出发，推导云白牌化、Super App 短路、中介抽成被压缩等连锁反应（ref: 05:41; 06:03）。
3. **阵营地图化**：用“Google TPU 端到端” vs “英伟达 GPU 生态”把硬件与上层模型/应用的投资与创业机会分层归类（ref: 15:20; 17:14）。
4. **用收入/成本拆账来对抗情绪**：把 1.4T 算力承诺拆成摊销、年烧钱规模、以及可见收入（订阅/广告/电商）来做压力测试（ref: 06:50; 07:54; 08:06）。
5. **识别范式天花板**：当“预训练数据见顶/激活参数不再无限变大”出现时，优先关注下一范式，而不是继续卷同一条曲线（ref: 36:50; 37:00）。
6. **Online Learning 作为第三范式路线图**：把“边交互边学习”视作核聚变级别跃迁，并明确其依赖基础设施（更长 context、相关训练技巧等）（ref: 37:20; 38:17）。
7. **机器人：数据管线优先**：比较各家真机数据采集方式、数据规模与利用率，用数据资产而非 demo 评估长期胜率（ref: 01:00:10; 01:03:31）。
8. **把鲁棒性拆成可打分步骤**：用“每一步打分 + value/credit assignment”的方式评估任务执行质量，从成功/失败中学习（ref: 01:02:05; 01:02:21）。

## 3. 提问技巧（采访方法）

1. **先给结论再追原因**：用“AI War”这种强判断开场，再立刻追问“为什么输不起”，把观点变成可验证的因果链（ref: 04:45; 05:10）。
2. **要求现实例子**：当嘉宾给出宏观判断时，主持人用“举一个现实例子（商业上）”迫使落到可感知的行业变化（ref: 05:16; 05:19）。
3. **追问泡沫的导火索**：把“泡沫”从情绪话题变成事件与数据（1.4T/30GW）的讨论对象（ref: 06:34; 06:45）。
4. **逼出收入构成的拆解**：用“能不能拆解 OpenAI 的收入构成”把估值争论落回现金流与变现路径（ref: 07:54; 08:04）。
5. **让嘉宾做阵营概览**：用“有哪些推动方/分成哪些阵营”来组织复杂信息，帮助听众建立地图（ref: 15:10; 15:20）。
6. **让嘉宾提炼关键词**：用“闭上眼睛最想传递几个关键词”获得高密度总结，并作为后续展开的目录（ref: 17:52; 17:56）。
7. **追问‘常态’与‘范式’**：例如“交替领先会是常态吗”，把讨论从短期新闻拉到长期结构（ref: 18:47; 18:53）。
8. **用相对刻度评估进展**：用“离 GPT-4 时刻还远吗”把机器人进展放到直观参照系里（ref: 01:04:27; 01:04:35）。

## 4. 可进一步验证/挖坑

1. **战争叙事的可观测信号**：即使短期现金流不优，巨头是否仍持续加码 CAPEX/人才？哪些指标能区分“泡沫退潮”与“战争升级”（ref: 05:07; 06:45）。
2. **云白牌化是否发生**：开发者决策是否从“选云”迁移到“选模型”，云厂商利润率/议价权是否被挤压（ref: 05:19; 05:31）。
3. **Agent 对中介抽成的冲击**：出行/旅行/搜索等平台的 take rate 是否下降？哪些品类最先被“信息对称化”（ref: 05:56; 06:03）。
4. **两大阵营的长期均衡**：TPU 的外溢采用、GPU 供给与先进制程产能配置，是否会让“交替领先”持续（ref: 15:22; 17:03）。
5. **收入集中度是否维持**：最领先三家模型是否长期拿走 80%-90% 的 AI-native 收入，还是会被应用层重新分配（ref: 19:21; 19:26）。
6. **Online Learning 的突破信号**：是否出现可复现的“边交互边学习”能力提升（更少数据、更快学习、持续泛化），以及对应的基础设施是否成熟（ref: 37:20; 38:17）。
7. **“真问题/假问题”清单**：用可量化的泛化指标验证 online learning 是否确实比世界模型/多模态更决定性（ref: 39:52; 40:12）。
8. **机器人数据资产的胜负手**：真机数据规模、采集成本、利用率与跨设备通用性是否能预测长期产品化速度（ref: 01:00:29; 01:00:50）。
