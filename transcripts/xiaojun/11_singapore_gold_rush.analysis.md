# 访谈分析笔记

## 摘要
1. 韩亦东（Neil）北大毕业后在新加坡16年，经历了从互联网出海到Web3的多轮淘金热，现创办Web3基础设施公司Radio。
2. 新加坡淘金热的三大驱动力：政策宽松（先发展后监管）、华人文化相通的落脚点效应、资金涌入形成的网络效应。2022年9月Token 2049达到顶峰，一周100+场Web3活动。
3. 新加坡政府的创业支持体系极为慷慨——企业发展局下属机构被创业者戏称为"慈善机构"，占股但出让条件极简单；政府还通过公积金制度让国民有安全网去冒险。
4. 新加坡创业与国内最大的不同：市场小但国际化程度高，必须从Day 1就面向全球；政商关系透明，官员薪资与GDP挂钩，腐败成本极高。
5. Neil团队曾做出亚太第一款短视频产品（比头条早4-5年），但因市场太小未能规模化——小市场的先发优势不等于全球竞争力。

## 反共识/非显然观点
1. 新加坡人主动往公积金账户多存钱（非政府要求）——高度自律的国民性格与政府制度设计形成正循环，这在其他国家几乎不可想象。
2. Web3在新加坡的火爆不是因为新加坡本身有多好，而是因为中国政策收紧后的"逼上梁山效应"——共享单车、P2P现金贷、交易所，每一波出海都有政策推力。
3. 淘金热有明确的时间拐点：2022年4-5月前融资容易，之后TERRA归零+FTX暴雷让投资人极度谨慎，全球融资都变得极难。
4. 新加坡官员薪资与GDP挂钩——这个制度设计让官员有动力推动经济增长，同时高薪降低了腐败动机，是一种"用市场化手段解决治理问题"的思路。
5. 淡马锡投FTX亏损数亿美元，但新加坡社会对此的反应相对理性——因为整体投资组合表现优异，单笔失败可以被容忍。

## 可学习的点
1. **"先做再说"的出海策略**：不要等市场完美再出海，新加坡作为跳板的价值在于低成本试错+辐射东南亚+连接全球资本。
2. **小市场的产品验证陷阱**：在新加坡验证成功不等于全球可行——Neil的短视频产品证明了这一点，小市场的PMF可能是假信号。
3. **政府资金的杠杆效应**：新加坡企业发展局的创业资助模式值得研究——占股但条件宽松，本质是用国家资本降低创业风险。
4. **多轮淘金热的规律**：每次国内政策收紧都会催生一波出海潮（互联网→P2P→Web3），识别这个规律可以提前布局。

## 提问技巧
1. **时间线梳理法**：让嘉宾按时间线回顾多轮淘金热（16-18年互联网出海→21年Web3→22年顶峰→衰退），用历史纵深制造洞察。
2. **内部人视角挖掘**：追问"只有本地人才知道的细节"——淡马锡、公积金、官员薪资制度，这些是外部观察者无法获取的信息。
3. **个人经历与宏观叙事交织**：Neil自己的创业故事（短视频先驱、Twilio经历）与新加坡宏观趋势交替展开，避免纯宏观分析的枯燥。

## 可进一步验证/挖坑
1. **新加坡企业发展局的创业资助具体条款**：占股比例、出让条件、成功率数据？
2. **亚太第一款短视频的失败复盘**：比头条早4-5年但未能规模化，具体原因是什么？是市场太小还是产品方向问题？
3. **Web3寒冬后新加坡的政策转向**：FTX事件后新加坡是否收紧了对加密货币的监管？
4. **新加坡官员薪资与GDP挂钩的具体机制**：如何计算？是否有公开数据？其他国家是否有类似实验？
