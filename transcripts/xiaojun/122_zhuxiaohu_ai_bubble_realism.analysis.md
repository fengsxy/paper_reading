# Analysis: EP122 朱啸虎现实主义故事的第三次连载

1. 一句话总结：
金沙江创投朱啸虎第三次与张小珺对谈，站在2025年末回望AI产业，认为泡沫至少三年内不会破裂，行业正从AGI叙事转向应用落地的现实主义阶段。

2. 关键洞察：
   - AI泡沫论是二级市场投资人在故意引导：悲观情绪的传导源头是希望回调以便再次布局，"大家都在讲泡沫的时候，泡沫肯定是没到的"。
   - Sam Altman的务实转向：2025年几乎不再提AGI，ChatGPT上线了更多应用化功能（Pulse、浏览器等），"嘴上说一套做的是另一套"，实际在做商业化。
   - 英伟达回调是健康的：朱啸虎认为回调为2026年多方爆发打好基础，但暗示有比英伟达更好的投资标的。
   - 中国AI创业越来越现实：从追逐大模型转向寻找真正的应用场景和商业模式，行业整体在"去泡沫化"。

3. Takeaway：
AI产业正处于从"讲故事"到"算账"的转折点。朱啸虎连续三年的观察记录了一个完整的周期：从狂热到冷静再到务实。对创业者和投资人而言，2026年的关键词不再是"颠覆"，而是"落地"和"盈利"。
