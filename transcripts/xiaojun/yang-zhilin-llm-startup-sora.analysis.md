# EP59: 59. 和杨植麟聊大模型创业这一年：人类理想的增量、有概率的非共识和Sora

## 一句话总结

与月之暗面创始人杨植麟对谈大模型创业一年的感悟，讨论非共识和Sora的影响。

## 关键洞察

1. 大模型创业的核心是找到人类理想的增量——AI能为人类带来什么新价值
2. 有概率的非共识是创业者最重要的判断力，共识性机会往往已经不是机会
3. Sora的出现标志着多模态AI进入新阶段，视频生成将重塑内容产业
4. 中国大模型创业面临算力、数据和商业化的三重挑战

## Takeaway

最好的创业机会藏在大多数人还没看到的非共识里。
