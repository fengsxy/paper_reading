# 访谈分析笔记

## 摘要
1. 张祥雨是阶跃星辰首席科学家，ResNet共同作者（论文引用37万+），AI圈公认的新一代华人AI科学家中最牛的人之一，本集是他人生第一次公开访谈。
2. 核心论点：静态图像的"生成-理解-人类对齐"三者是割裂的（不像语言的自闭环），这是CV领域始终无法出现GPT时刻的根本原因。
3. 万亿参数模型的反直觉发现：模型越大，通用对话/情商/知识量越强，但数学推理能力先升后降——大模型倾向于"跳步"，跳过中间推理直接给答案，导致错误率上升。
4. O系列（OpenAI o1）的出现是转机——通过强化学习让模型学会"慢思考"，解决了大模型跳步问题，也为多模态生成-理解一体化指明了方向。
5. 未来两年的两个GPT-4时刻预测：①多模态生成-理解真正一体化（通过RL+CoT解决视觉生成的可控性）；②视频理解+物理世界建模的突破。

## 反共识/非显然观点
1. **架构设计对大模型几乎没用**：只要大方向对（如用ResNet），层间连接细节差别不大；但对端侧小模型，架构细节极其重要——这与业界普遍重视架构创新的风气相悖。
2. **Contrastive Learning和MAE/MRM都是死路**：它们学到的不变性是handcraft的（人工设计的数据增强），不是data-driven的，因此永远没有scale up特性。张祥雨22年初发文批评MRM无用，当时被圈内批评，现在已被验证。
3. **万亿参数模型数学能力不如7B模型**：这不是数据质量问题，而是大模型的"跳步"本性——它见过太多pattern，倾向于直接pattern match而非逐步推导，这可能直接指向了next-token prediction的本质局限。
4. **GPT-3时代中国大模型失败的真正原因**：不是技术差距，而是严重低估了数据量需求——千亿参数只配了几百B数据，按今天标准完全倒置，模型处于严重欠训练状态。
5. **图像来自大自然，不包含人类理解**：这是一个深刻的哲学观点——语言是人类创造的（天然对齐），图像是自然存在的（天然不对齐），这决定了纯视觉自监督永远无法产生"理解"。

## 可学习的点
1. **Scaling的三要素同步论**：模型、数据、算力必须同时scale，任何一个落后都会成为瓶颈——AlexNet的成功恰好是三者同时到位的历史契机。
2. **生成-理解一体化的迭代策略**：用理解模型给生成模型打标→训练更好的生成模型→外挂回理解模型→循环迭代——虽然张祥雨说这条路没走通，但思路本身有启发。
3. **研究方向选择的判断框架**：看一个方法是否有scale up特性——如果少量数据就能学会（如遮挡不变性），那增加数据不会带来信息增量，这个方向就是死路。
4. **从NLP借鉴到CV的正确姿势**：不是简单搬方法（I-GPT/BEiT），而是理解NLP成功的本质（learn from data的自闭环），然后在CV中寻找等价物。
5. **算力需求的平方关系**：同时扩大模型参数和数据量，算力需求是平方级增长——这解释了为什么万亿参数模型的训练是"无底洞"。

## 提问技巧
1. **技术深度访谈的标杆**：主持人（广秘）本身有深厚的AI背景，能在ResNet→NAS→多模态→O系列的技术脉络中自如切换，这是做好技术播客的前提。
2. **"人生第一次公开访谈"的稀缺性**：张祥雨极其低调，这种独家性本身就是内容价值。
3. **用研究时间线串联**：从2012年读博→2016年ResNet→2019年NAS→2022年多模态→2024年万亿参数→O系列，用个人研究史串联整个AI发展史。
4. **追问反直觉发现**：万亿参数模型数学能力下降这个发现，主持人追问"这是不是业界非共识"，让嘉宾明确这是独家洞察。

## 可进一步验证/挖坑
1. **万亿参数模型数学能力下降的机制**：张祥雨的"跳步"假说是否有更严格的实验验证？其他万亿参数模型（如GPT-4）是否也有类似现象？
2. **O系列对多模态的影响**：RL+CoT是否真的能解决视觉生成的可控性问题？阶跃星辰在这个方向的进展？
3. **视频理解的GPT-4时刻**：张祥雨预测的时间窗口（2年内）是否准确？Sora之后视频生成的进展是否支持这一判断？
4. **阶跃星辰Step-2模型的后续**：万亿参数模型训练9个月后的实际表现？是否已经通过RL解决了数学推理问题？
5. **"图像不包含人类理解"这个论点的边界**：医学影像、卫星图像等专业领域的图像是否也适用？还是主要针对自然图像？
