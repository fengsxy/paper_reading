# EP42: 42.【汽车史话02】集权者福特与全球第二畅销T型车的衰落

## 一句话总结

探讨亨利福特的集权管理风格，T型车如何成为全球第二畅销车型，以及其最终衰落的原因。

## 关键洞察

1. 福特的流水线生产革命性地降低了汽车成本，让普通人也能拥有汽车
2. T型车的成功源于标准化和规模效应，但也埋下了僵化的种子
3. 福特的集权管理风格在早期推动了效率，后期却阻碍了创新和市场适应
4. T型车的衰落警示：即使是最成功的产品，也必须随市场需求演进

## Takeaway

福特的故事是创新者窘境的经典案例——成就你的东西，最终也可能束缚你。
