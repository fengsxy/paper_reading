# Hacker News Digest - 2026-02-22

## 🔥 Top Stories

### 1. How I use Claude Code: Separation of planning and execution (741 points, 472 comments)
[Link](https://boristane.com/blog/how-i-use-claude-code/)

Boris Tane 分享了他用 Claude Code 9 个月的核心工作流：永远不要让 AI 直接写代码，先做 Research（深度阅读代码库写 research.md）→ Plan（写实现计划）→ Annotate（反复审查标注）→ Todo List → Implement。核心观点：planning 和 execution 的分离是最重要的一步，能大幅减少 token 浪费和架构错误。472 条评论说明这个话题引起了广泛共鸣。

### 2. How far back in time can you understand English? (644 points, 338 comments)
[Link](https://deadlanguagesociety.com)

关于英语历史可理解性的有趣探索——你能听懂多久以前的英语？从现代英语一路回溯到古英语，展示语言演变的渐进过程。

### 3. Karpathy 谈 "Claws" — Agent 系统的新层 (355 points, 805 comments)
[Link](https://twitter.com/karpathy)

Karpathy 发推讨论 "Claws"（OpenClaw 类 agent 系统的统称），认为这是 AI stack 的新层——在 LLM agents 之上，负责编排、调度、上下文管理和持久化。805 条评论，是今日讨论最热烈的帖子。昨天也上了首页，热度持续。

### 4. Llama 3.1 70B on a single RTX 3090 via NVMe-to-GPU bypassing CPU (309 points, 81 comments)
[Link](https://github.com/xaskasdf)

通过 NVMe 直接到 GPU 的数据通路绕过 CPU，在单张 RTX 3090 上运行 Llama 3.1 70B。思路是利用 GPUDirect Storage 把模型权重从 NVMe SSD 直接加载到 GPU 显存，避免 CPU 内存瓶颈。对本地部署大模型有实际意义。

### 5. How Taalas "prints" LLM onto a chip (283 points, 140 comments)
[Link](https://anuragk.com)

深入解析 Taalas 如何将 Llama 3.1 8B 硬编码到专用芯片上，实现单用户 17K tokens/sec。核心思路：为每个模型定制专用硅片，统一存储与计算，消除 HBM/先进封装/液冷需求。昨天 Taalas 官方文章上了首页，今天是第三方技术解析。
