# 从奶茶到图灵完备

有天我在群里发了条消息：

> 香飘飘就像 ResNet，早已不是 SOTA 但引用的论文可绕地球三圈，胜在经典常品常新。一点点就像 CLIP，追求极致效果确实差点意思，但保底通用，信手拈来。茶颜悦色就像 DINO v2，很有 mid-2020 大厂的工匠精神，花里胡哨的 trick 加了一堆，事实上的 SOTA，但总觉得少了一丝初代目的灵气。
>
> 以及大家都要在 COCO 上比一比。

朋友说这个比喻不错。我开始想：为什么这种跨领域的类比会让人觉得"对"？奶茶和深度学习模型明明是完全不同的东西，但你一看就知道哪个对哪个，而且觉得挺准。

这到底是在做什么？

## Hofstadter 说：这就是智能

Douglas Hofstadter 在《Gödel, Escher, Bach》里花了 750 页讲一件事：智能的核心操作是在不同系统之间发现结构上的对应关系。他后来在《Surfaces and Essences》里把话说得更直接——思维就是类比。

奶茶市场有一个竞争格局：经典老牌、通用型选手、精雕细琢的新贵。ML 模型也有一个竞争格局：经典 baseline、通用 backbone、堆 trick 的 SOTA。这两个格局在结构上是同构的。你做的事情是把一个领域的结构映射到另一个领域，发现它们共享同一个抽象骨架。

这个操作看起来很轻松，但仔细想想，它要求你同时理解两个领域的内部逻辑，然后在它们之间找到保持关系的映射。这不是简单的"A 像 B"，是"A 内部各元素之间的关系，跟 B 内部各元素之间的关系，是一样的"。

Hofstadter 认为这就是智能在做的事。不是逻辑推理，不是搜索，不是优化——是类比。

## 但 GEB 真正想说的不是类比

GEB 的主线其实是另一个概念：strange loop。

一个系统有很多层抽象。底层是符号操作，高层是语义、概念、"意义"。正常情况下信息是自底向上流的——神经元放电 → 模式 → 概念 → 想法。但 strange loop 说的是：高层的东西能反过来影响底层。你想到"我要举手"，手就举了。一个关于自身的概念，改变了产生这个概念的物理过程。

Hofstadter 认为这就是意识。"我"这个概念是大脑对自身的一个模型，而这个模型反过来能驱动大脑的活动。高层指向底层，底层产生高层，形成闭环。

他用 Gödel 不完备定理做类比：一个足够强的形式系统，能构造出一个命题说"我在这个系统里不可证"。这个命题在谈论自己所在的系统——自指。Gödel 证明了这不是人为设计的 trick，而是系统表达力足够强之后的必然产物。

那类比和 strange loop 是什么关系？

类比是产生自指的手段。你要实现自指，系统得能把自己映射成自己能处理的对象。Gödel 怎么做的？他把证明过程编码成自然数——证明过程和自然数是两个不同的东西，但他找到了它们之间的结构映射。这本身就是一次类比。有了这个映射，系统才能"谈论自己"。

所以：类比是引擎，自指是引擎跑出来的特殊结果，strange loop 是自指持续运转形成的稳定结构。

这个框架漂亮，但不闭合。"为什么自指就产生了意识"这一步，Hofstadter 更多是靠直觉而不是证明。不过这不影响他的核心洞察：足够复杂的系统，必然产生某种形式的自指。

## 什么是"足够复杂"？

这就要说到图灵机了。

图灵 1936 年想回答一个问题：计算到底是什么？什么问题是原则上可以算的，什么是不管你怎么努力都算不出来的？

他的做法是把一个人拿着笔在纸上算题的过程，抽象到不能再抽象。一个人在算题的时候本质上在做什么？

1. 看纸上写的某个符号
2. 根据符号和脑子里的状态，决定写什么
3. 把注意力移到旁边
4. 脑子切换到新的状态
5. 重复

图灵机就是这四件事的形式化。一条无限长的纸带，一个读写头，一张规则表。每一步做的事情是：

**(当前状态, 读到的符号) → (写什么, 往哪移, 新状态)**

没有"加法"，没有"排序"，没有任何高级操作。所有计算都是这一个原子操作的组合涌现出来的。

举个例子，二进制加 1（比如 1011 → 1100）：

```
规则表：
(找右端, 0) → 写0, 右移, 找右端
(找右端, 1) → 写1, 右移, 找右端
(找右端, _) → 不写, 左移, 加法
(加法,   1) → 写0, 左移, 加法      ← 进位
(加法,   0) → 写1, 停机            ← 不用进位了
(加法,   _) → 写1, 停机            ← 最高位进位
```

六条规则，实现了二进制加法。整台"计算机"就是一张这样的表。

## 图灵完备

普通图灵机的规则表是写死的，一台机器只能做一件事。但图灵发现你可以造一台特殊的图灵机：它的纸带上放的是另一台图灵机的规则表和输入数据，然后它读取这些规则并模拟执行。这就是通用图灵机——一台能模拟任何图灵机的图灵机。

这其实就是"可编程"的意思。你的电脑硬件不变，装不同的软件就能做不同的事。你的电脑就是一台通用图灵机的物理实现。

一个系统如果能模拟通用图灵机，它就是图灵完备的。你需要三样东西：

1. 条件分支——根据读到的东西决定做什么
2. 循环/跳转——能回到之前的步骤
3. 无限存储（理论上）

图灵完备不是一个很高的门槛。Python 是，C 是，Excel 公式是，Minecraft 红石电路也是。但它的深刻之处在于：一旦过了这个门槛，计算能力就到顶了。Python 和图灵机的纸带，计算能力完全相同。

而 Gödel 告诉你，到了这个门槛，自指就不可避免了。图灵完备 = 表达力够强 = 能谈论自身 = 有些关于自身的问题永远回答不了（不完备/停机问题）。

能力和局限是同一枚硬币的两面。

## Transformer 图灵完备吗？

这是个有明确学术结论的问题，但答案取决于你怎么定义"Transformer"。

**标准 Transformer：不是。**

固定层数、固定精度的 Transformer 是一个有限深度的前馈网络。12 层的 Transformer，遇到需要 13 步递归的问题，理论上就做不到。它没有循环，计算步数被层数锁死了。

**加上无限精度：是。**

Pérez et al. (2019) 证明了，给 Transformer 无限精度的注意力计算，它就是图灵完备的。思路是把图灵机的时间步展开到序列的空间维度上——图灵机跑 T 步，就给 Transformer 一个长度为 T 的序列。用注意力机制当读写头精确定位纸带位置，用 FFN 层当状态转移规则。循环没了，但序列可以无限长，所以计算步数还是无限的。

**RNN 更自然：**

RNN 天然长得像图灵机——有隐藏状态（对应图灵机的状态），每一步读输入、更新状态、循环。Siegelmann & Sontag (1996) 证明了有限神经元 + 无限精度权重的 RNN 是图灵完备的。用隐藏状态的实数值编码纸带内容，通过乘 2 / 除 2 来模拟读写头的左移右移。

两个证明的共同点：都依赖不现实的假设（无限精度或无限长度）。实际的 RNN 和 Transformer 都不是图灵完备的。

但实际中，LLM 有一个 hack：自回归生成。每一步的输出变成下一步的输入，相当于用外部的"纸带"（生成的 token 序列）扩展了计算深度。Chain of Thought 就是在利用这个——把中间计算结果写出来，绕过固定深度的限制。

所以理论上 RNN > Transformer，实际中 Transformer + CoT ≈ RNN。

## 回到类比

dLLM（discrete diffusion language model）不是自回归的，没有天然的"把输出当输入"这个循环。但 remask 在做类似的事——把中间结果打回去重新处理，相当于增加了有效计算深度。这也许是 remask 能帮助推理的一个理论解释：它给了 dLLM 一种原本没有的递归能力。

从奶茶的同构讲到这里，其实一直在做同一件事：在不同的系统之间找结构映射。奶茶和 ML 模型之间、Gödel 和图灵之间、RNN 和图灵机之间、CoT 和 remask 之间。

Hofstadter 说这就是智能。我不确定他是对的，但至少这个过程本身挺有意思的。
