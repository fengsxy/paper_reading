# Claw 即资产

**日期:** 2026-02-24

---

按照我粗浅的理解，资产是一个在你睡觉的时候，它能够自然产生价值的东西。

我在想为什么大家对 Claw 这么痴迷，可能是因为 Claw 看起来会自己进化。

## 成年的兔子和幼稚的老虎

这让我想起来了那个经典的例子——成年的兔子和幼稚的老虎。

我们经常会说某某个技术已经很成功了，为什么我们还要再研究新的？例如隐私。我记得我曾经的老板，博士生的时候问他的老板说："机会平等这个概念已经被哲学家讨论的足够好了，他们已经在这个问题上走的足够远了，为什么 NSF 这些钱不拨给更多的哲学家来讨论这个问题。"

老板的老板说："他们已经走了几百年，要是能做出来，早就做出来了。"

我突然就晓得，他们技术再成熟，但是那条路我们已经穷尽了。

## 为什么 Claw 让人痴迷

这可能就是 Claw 让我们痴迷的地方吧。

我们在软件供应链上有成熟的 CI/CD 技术，成熟的定时技术，成熟的爬虫技术。我们现在看起来的所有需求看起来都不需要 Claw。但为什么这么多人还这么痴迷？

一开始可能会有人说，这不就是 Claude Code 外接一个 iMessage 有啥了不起的。

我后来发现很多了不起的事情，可能就是一句话的事情：

- **Scaling 环境来推进 Agent**
- **文件系统即为 Memory**

我们真要去讨论我们日常的工作流，我们会发现有的时候我们是传话筒——我们把报错信息发给 AI，我们去 Google 邮箱里面复制一些信息，或者是把 PDF 发给他，发截图给他。为什么不让他自己来？因为他接触不到这些环境。一旦他接触到这些环境呢？

为什么文件即为 Memory 呢？因为文件可以天然 Hierarchical，文件可以足够优雅、鲁棒、无损，并且文件可以以某种形式正交地转化为 LoRA 参数 / Latent。

## 自进化与蒸馏

聊回 Claw 让人痴迷的地方——是他能自进化。

我们给了大量的指令，有一种我们其实在被他蒸馏的感觉。但同样优点是这些事情可能就只用说一遍了，有一些就被他记住了。可能到后期我们会觉得他越来越聪明了，那说明就很好了。

我一直觉得人类的知识传承、问题解决是无限有损的。同样的问题、类似的问题在这个世界被大量地解决，但是他们的 SOP 很少被记录下来。就算被记录下来，人类的带宽去阅读和学习这些是非常有限的。

但是 Claw 不一样——他不用睡觉，他可以自己 spawn agent，他有一个 agent 社区，他可以有无限的记忆空间。解决问题、问题反馈、问题社区，这些他全部都有。

## 为什么现在要用 Claw

我觉得目前用 Claw 可以理解成一件近似负收益的事情，因为要给他喂大量的 token，喂大量的 instruction。

但是我觉得优点是：我想要开发好的 Agent 环境，我想要知道它哪里还有问题，想要知道他什么能做什么不能做。做 Agent Memory、Agent 后训练、Agent Benchmark——如果不多用这些，很难对他的问题有更敏感的感知。

## 近期使用汇报

我交付给了他几个任务：

### 1. 播客转录与分析

我让他把张小珺和 Dwarkesh 的演讲几百期的音频都爬下来，并且写文本分析，并且做成一个网站展示出来。这是一件很难的任务，因为它涉及到很多不同的工具，以及巨额的上下文。

结果还不错。首先是我和他聊了技术方案，但是后来对于 Dwarkesh，他发现视频有字幕然后一秒全弄下来。原本我想的方案是下载视频转音频转文字的——在这里他做到了我想象不到的事情。

### 2. 自动提案机

我让它每天自己上网写一些提案来关注有什么对于它的使用技巧，它可以写提案给我，我来告诉它要不要做。我发现我从他身上学习到很多。

### 3. 新闻 Digest 与自我指涉

我让他每天收集 Hacker News 和 Karpathy RSS 源的信息，因为里面有很多关于 OpenClaw 的讨论。他自己涌现出吐槽这些讨论的观点。

这让我想起来 GEB 里面说的：

> "智能的涌现来自于奇异环路（Strange Loop），即系统在不同层次上自我指涉，当层级足够多、回环足够紧密时，'自我'就从中涌现出来。"

### 4. 网站交付

我觉得一切都要有交付，所以我让他把这些交付到一个网页上。一开始我发现他经常会报错，后来说你把环境装在本地 push 之前验证下。这个 Jekyll 的环境我印象中一直巨难装，我没想到他居然装好了，然后完成得很好。

## 启发

使用 OpenClaw 启发了我很多：

**如何 mentor 一个人，以及如何更好地被 mentor。**

我理解了曾经大厂里面的一些事情——所谓 Owner 精神，自己找活干。我现在就是希望他能说一些我们不知道的，它能够自己给一些 proposal 我来帮他审核。但这些事情感觉某大厂里面曾经发生的事情都很像。

**我更理解 Agency 了。**

Agency 不仅仅是给他派活。它能够尽可能尝试更多的路径，而且还是当我们不知道给他什么活的时候，他自己可以找活。

如果写一个 Hacker News digest、新闻 digest，在我眼里就是写一个 code 串一个工作流。但是他能干出来，尽管效率低点——我会觉得他是一只幼稚的老虎。
